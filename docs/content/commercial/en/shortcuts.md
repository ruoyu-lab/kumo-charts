# Keyboard shortcuts

While the chart has the focus (after clicking it, say), the keys below work, as in the usual market software. On a Mac, Alt is ⌥, Ctrl is ⌘ and Shift is ⇧, and the interface writes them so too. They do not fire while typing in a field; in windows, dialogs and menus, only keys with Alt or Ctrl work. `?` or Ctrl+/ opens the list of shortcuts; the tooltips of the top bar's buttons and of the drawing toolbar, and context menus, show the keys too.

| Key                                                                             | What it does                                                                                                                                                                                                                                | Toggle needed                               |
| ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| Typing letters                                                                  | Opens the symbol search with the letters typed filled in                                                                                                                                                                                    | `symbolSearch`                              |
| Typing a number, optionally followed by the unit `s`, `m`, `h`, `D`, `W` or `M` | Shows the timeframe to switch to on the current chart, as `15` for 15 minutes, `4h` or `1D`; Enter switches and Esc cancels. A timeframe not in the list of timeframes that the datafeed can build is added to the user's custom timeframes |                                             |
| `/`                                                                             | The indicators window                                                                                                                                                                                                                       | `indicators`                                |
| `?`, Ctrl+/                                                                     | The list of shortcuts                                                                                                                                                                                                                       |                                             |
| ← → (half a screen with Shift held)                                             | Scroll left and right                                                                                                                                                                                                                       |                                             |
| ↑, + / ↓, −                                                                     | Zoom in / zoom out                                                                                                                                                                                                                          |                                             |
| End                                                                             | Go to the latest bar                                                                                                                                                                                                                        |                                             |
| Alt+R                                                                           | Reset chart view                                                                                                                                                                                                                            |                                             |
| Alt+I, Alt+L, Alt+P                                                             | Invert scale, logarithmic scale, percent scale (pressed again, back to regular)                                                                                                                                                             |                                             |
| Alt+A                                                                           | Opens the alert window with the crosshair's price filled in, or the latest price when the pointer is not on the main pane                                                                                                                   | `alerts`                                    |
| Alt+S                                                                           | Screenshot (download image)                                                                                                                                                                                                                 | `screenshot`                                |
| Alt+Shift+S                                                                     | Copy image to the clipboard                                                                                                                                                                                                                 | `screenshot`                                |
| Esc                                                                             | Cancels the drawing in progress, or picking the start of a replay                                                                                                                                                                           |                                             |
| Alt+T, Alt+H, Alt+J, Alt+V, Alt+C, Alt+F, Alt+Shift+R                           | Trend line, horizontal line, horizontal ray, vertical line, cross line, Fib retracement, rectangle (Alt+R is already reset view); pressed again, it cancels                                                                                 | `drawings`, with the tool in `drawingTools` |
| Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z                                                   | Undo / redo drawings                                                                                                                                                                                                                        | `drawings`, `history`                       |
| Delete, Backspace                                                               | Remove the selected drawing                                                                                                                                                                                                                 | `drawings`                                  |
| Ctrl+C, Ctrl+V                                                                  | Copy and paste the selected drawing                                                                                                                                                                                                         | `drawings`                                  |

The shortcuts of a feature turned off do nothing and are not in the list. `features: { shortcuts: false }` turns off every shortcut, including the chart's own keys such as the arrows and Delete, and hides the "Keyboard shortcuts" toggle under "Controls" in the chart settings with them; users can also turn off shortcuts for a chart with that toggle.
