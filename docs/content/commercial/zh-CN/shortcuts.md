# 快捷键

图表里有焦点时（比如点过图以后）可以用下面的键，和主流看盘软件的习惯一样。Mac 上 Alt 是 ⌥、Ctrl 是 ⌘、Shift 是 ⇧，界面上也这样写。在输入框里打字时不触发；窗口、对话框和菜单里只有带 Alt、Ctrl 的键有效。按 `?` 或 Ctrl+/ 打开快捷键列表；顶栏按钮和画线栏的提示、右键菜单里也写着对应的键。

| 键                                                    | 作用                                                                                                                                               | 需要的开关                             |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| 直接输入字母                                          | 打开品种搜索，已经填好输入的字母                                                                                                                   | `symbolSearch`                         |
| 输入数字，可以接单位 `s`、`m`、`h`、`D`、`W`、`M`     | 在当前图上显示要切换的周期，如 `15` 是 15 分钟、`4h`、`1D`；Enter 切换，Esc 取消。周期列表里没有、但数据源合成得了的周期，会加到用户的自定义周期里 |                                        |
| `/`                                                   | 指标窗口                                                                                                                                           | `indicators`                           |
| `?`、Ctrl+/                                           | 快捷键列表                                                                                                                                         |                                        |
| ← →（按住 Shift 走半屏）                              | 左右平移                                                                                                                                           |                                        |
| ↑、+ / ↓、−                                           | 放大 / 缩小                                                                                                                                        |                                        |
| End                                                   | 回到最新的 K 线                                                                                                                                    |                                        |
| Alt+R                                                 | 重置图表视图                                                                                                                                       |                                        |
| Alt+I、Alt+L、Alt+P                                   | 反转坐标、对数坐标、百分比坐标（再按一次回到常规）                                                                                                 |                                        |
| Alt+A                                                 | 打开提醒窗口，填好十字线的价格；指针不在主图上时用最新价                                                                                           | `alerts`                               |
| Alt+S                                                 | 截图（下载图片）                                                                                                                                   | `screenshot`                           |
| Alt+Shift+S                                           | 复制图片到剪贴板                                                                                                                                   | `screenshot`                           |
| Esc                                                   | 取消正在画的线、选回放起点                                                                                                                         |                                        |
| Alt+T、Alt+H、Alt+J、Alt+V、Alt+C、Alt+F、Alt+Shift+R | 趋势线、水平线、水平射线、垂直线、交叉线、斐波那契回撤、矩形（Alt+R 已是重置视图）；再按一次取消                                                   | `drawings`，且工具在 `drawingTools` 里 |
| Ctrl+Z / Ctrl+Y、Ctrl+Shift+Z                         | 撤销 / 重做画线                                                                                                                                    | `drawings`、`history`                  |
| Delete、Backspace                                     | 删除选中的画线                                                                                                                                     | `drawings`                             |
| Ctrl+C、Ctrl+V                                        | 复制、粘贴选中的画线                                                                                                                               | `drawings`                             |

开关关掉的功能，它的快捷键不起作用，也不出现在列表里。`features: { shortcuts: false }` 关掉全部快捷键，包括方向键、Delete 这些图自己的键，图表设置「操作」里的「键盘快捷键」开关也随之隐藏；用户也可以用这个开关给某张图关掉快捷键。
