# 比较品种

顶栏品种名后面的 ⊕ 打开比较窗口，搜索品种，点一行（或回车）按「相同百分比坐标」加上；指针移到一行上时右边出现三个按钮，可以选：

| 位置                   | 接口里的 `placement` | 怎么画                                                                                                                          |
| ---------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 相同百分比坐标（默认） | `percent`            | 画在主图的价格坐标上，坐标切到百分比；每个品种都从视野内第一根 K 线的收盘价算起，都从 0% 开始，各按自己的涨跌走，拖动缩放时重算 |
| 新价格坐标             | `scale`              | 画在主图上，用自己的价格坐标：第一个放在左侧价格轴，再有的不带坐标轴（数值看图例）                                              |
| 新窗格                 | `pane`               | 单独一个窗格，用自己的价格坐标                                                                                                  |

窗口上方列着当前图已比较的品种，每个可以去掉；窗口加完不关，可以接着加。主图在常规或对数坐标时，加上「相同百分比坐标」的品种会切到百分比（指数化到 100 时不变，同样每个品种从自己的第一根算起）；之后可以在价格轴右键菜单里改回常规。

- 比较的品种按图当前的周期取数据（和主图一样，由数据源的 K 线周期合成），往左拖加载更早的 K 线时跟着加载，有实时数据时跟着走（推 K 线或推成交都可以）；回放时一样只显示回放到的部分。
- 图例里一行显示它的名称和收盘价（按它自己的价格小数位），价格轴上标出它的最新值（百分比坐标上是百分比），和最新价的标签重叠时自动错开。指针移到这一行上有显示/隐藏、设置、删除按钮；设置窗口里可以改位置、样式（和图表类型同名同画法：美国线、K线图、空心K线图、线形图、带标记线、阶梯线、面积图、HLC区域、基准线、柱状图、高-低，接口里的 `style` 是 `ohlc`、`candles`、`hollow-candles`、`line`、`line-markers`、`step-line`、`area`、`hlc-area`、`baseline`、`columns`、`high-low`）、颜色和线宽（线和面积这五种；其余用涨跌颜色），改动即时生效。不设颜色时从调色板末尾依次取色，避开指标常用的颜色。
- 换主图品种时比较的品种保留；每张图各有自己的比较品种，存在 `ChartView.comparisons` 里（`{ id, symbol, placement, style, color, width, visible }`）。

```ts
const id = await chart.addComparison('ETHUSDT'); // 相同百分比坐标
await chart.addComparison('XAUUSDT', { placement: 'pane', style: 'area' });
await chart.updateComparison(id, { color: '#0d9488', width: 3 });
chart.on('comparisonsChange', ({ chart: index, comparisons }) => save(index, comparisons));
```
