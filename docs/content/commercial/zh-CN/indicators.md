# 指标

指标窗口是一个不挡图表的小窗，按住左边栏或顶部的空白处可以拖到任何地方，关上再打开还在原处。左边栏用分割线分成三块：全部；收藏、指标模板；趋势、通道、震荡、成交量、波动、订单流（页面自己的指标没有分组时另有「其他」）。右边顶上是所选分类的标题和关闭按钮，下面是搜索框（指标模板页是模板名称和保存按钮）。窗口列出图表库指标模块的全部 87 个指标（每张图都注册好了）、开源图表库的两种成交量分布（`@kumo-charts/core/volume-profile`：VPVR 可见范围、VPSV 每日），以及商业版订单流的 3 个指标（数据源有 `getTradeMinutes()` 时）、大单和订单簿热力图（数据源有 `subscribeBook()` 时）：

| 分组   | 指标                                                                                                                                                                                                                                                                                                                                                      |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 趋势   | MA、EMA、SMMA、WMA、HMA、KAMA、ALMA、VWMA、BBI、ICHIMOKU、SAR、SUPERTREND、ALLIGATOR（鳄鱼线）、CHANDELIER（吊灯止损）、FRACTALS（分形）、DMI、DMA、TRIX、AROON、DEMA、TEMA、LSMA（最小二乘均线）、MCGINLEY（麦金利动态均线）、RIBBON（均线带）、VSTOP（波动止损）、CKSTOP（钱德克罗止损）、VORTEX（涡旋指标）、PIVOTHL（高低枢轴点）、ZIGZAG（之字转向） |
| 通道   | BOLL、KC、DC、PIVOTS（枢轴点）、PREVHLC（上一周期高低收）、SESSIONS（交易时段）、ENVELOPE（包络线）、MIKE（麦克支撑压力）                                                                                                                                                                                                                                 |
| 震荡   | MACD、RSI、KDJ、STOCH（慢速随机指标）、STOCHRSI、WR、CCI、BBP（布林带 %B）、ROC、BIAS、MTM、DPO、PSY、BRAR、FISHER（费雪变换）、AO（动量震荡指标）、PPO、CMO、UO、KST、COPPOCK（估波曲线）、TSI、SMI、RVGI、BOP（均势指标）、CRSI（康纳斯 RSI）、ASI（振动升降指标）、CR（能量指标）                                                                      |
| 成交量 | VOL、OBV、VR、EMV、MFI、CMF（蔡金资金流）、AD（累积/派发线）、CHAIKINOSC（蔡金震荡指标）、PVT（量价趋势）、VO（成交量震荡）、EFI（强力指数）、KVO（克林格震荡）、WVAD（威廉变异离散量）、RVOL（同时段相对成交量）、VWAP、VPVR、VPSV                                                                                                                       |
| 波动   | ATR、STD、CHOP（震荡指数）、ADR（日均波幅）、HV（历史波动率）、MASS（梅斯线）、BBW（布林带宽度）                                                                                                                                                                                                                                                          |
| 订单流 | VD（成交量差）、CVD（累计成交量差）、UDV（主动买卖量）（这三个数据源有 `getTradeMinutes()` 才有）、LARGETRADES（大单）、BOOKHEATMAP（订单簿热力图，数据源有 `subscribeBook()` 才有）                                                                                                                                                                      |

每个指标都可以在指标窗口里用代码或任何一种语言的名称搜到，在设置窗口里改参数、线条和参考线：

- 由一种价格算的指标（均线类，包括 DEMA、TEMA、LSMA、MCGINLEY、RIBBON；BBI、ALLIGATOR、BOLL、KC、ENVELOPE、VSTOP、MACD、RSI、STOCHRSI、WR、CCI、ROC、BIAS、DMA、TRIX、MTM、DPO、PSY、FISHER、AO、PPO、CMO、KST、COPPOCK、TSI、CRSI、STD、BBW、BBP、VWAP）可以选价格：收盘、开盘、最高、最低、(H+L)/2、(H+L+C)/3、(O+H+L+C)/4。FISHER、AO 和 ALLIGATOR 默认 (H+L)/2，VWAP 默认 (H+L+C)/3。
- 选项类参数是下拉框或分段按钮：PIVOTS 的类型（标准、斐波那契、伍迪、经典、德马克、卡玛利拉）和 PIVOTS、PREVHLC、ADR 的周期（日、周、月、季、年，按品种的交易日历）。接口里用选项的数字：`addIndicator('PIVOTS', { params: { kind: 1, period: 1 } })` 是按周的斐波那契枢轴点。
- RIBBON（均线带）是四条均线，每条有自己的类型（SMA、EMA、SMMA (RMA)、WMA、VWMA）和周期，默认 20、50、100、200 的 SMA；不要哪条就在样式页把它关掉。
- PIVOTHL（高低枢轴点）的高点、低点各有左右两边的 K 线数（默认都是 10），每个枢轴点在它那根 K 线上画三角并写出价格。
- ZIGZAG（之字转向）连起价格的拐点：参数有拐点偏离（%，默认 5）、拐点深度（默认 10，左右各一半的 K 线确认）、延伸到最新 K 线，以及标签写什么——拐点价格、拐点涨跌（绝对值或百分比）、累计成交量（从上一个拐点之后到这个拐点），默认都开着。最后一个拐点会随行情被更远的同向拐点替换，线和标签跟着动。高点的标签在上方、用主题的涨色，低点的在下方、用跌色，都画在绘图区里，不压价格轴；样式页只有一条「之字线」，可以改颜色、线宽、线型，关掉它线和标签都不画。按别的周期算时，拐点画在那个周期的 K 线收完的位置，成交量是那个周期的 K 线的量加起来。
- 水平段（枢轴点、上一周期高低收、ADR）和线一样可以改颜色、线宽、线型。交易时段的方框（东京、伦敦、纽约股市的交易时间，各按自己的时区和夏令时）可以分别改颜色、单独隐藏，设置里写着各时段的时间。
- 线的名称按界面语言显示：图例、样式页、提醒窗口和提醒文字里，布林带是中轨、上轨、下轨，MACD 是柱状图、MACD、信号线；MA9、%K、R1 这类代码各种语言都一样，页面自己的指标用它自己给的名称。图上 `chart.indicators.valuesAt()` 的 `label` 也是界面语言的名称。
- 主图上的指标在样式页有「参与价格轴缩放」：关掉后它的线不参与价格轴的自动缩放，离价格很远时画在图外，不会把 K 线压扁。枢轴点、上一周期高低收和交易时段的方框默认关着（R5、S5 这类离价格远），其他默认开着。接口里是 `autoscale`：`true`、`false`，或 `null` 按指标默认。
- 成交量分布（VPVR、VPSV）的参数里有「拆分方式」：**K 线涨跌**（默认，开源图表库的画法，每行按 K 线收涨、收跌分两种颜色）或 **主动买卖**（商业版订单流的画法）。选主动买卖时，每一行的量来自成交（每分钟每个价位的主动买卖量），前一段（贴着长出的那条边）是主动买入、后一段是主动卖出，总长还是总成交量；控制点和价值区域按总量算，和开源版一样；行数、价值区域、宽度、位置照旧生效，回放时只算已放出的部分。样式页的两种颜色换成主动买入量、主动卖出量（默认是主题的买、卖色），切换时原来设的两种颜色按位置带过去。只有数据源有 `getTradeMinutes()` 时才能选主动买卖，否则这个选项是灰的，下面写着原因。
  - 成交和成交量轨迹共用一份（同一品种的几张图也共用），从最新的往前取；一个分布（按交易日时是一天）的成交没到齐时不画它，在它的位置写「加载中」「无成交数据」或「加载失败」（稍后自动重试），图的左下角写一句原因。图刚打开时，当前这一分钟的成交要等它走完才能从历史补全，所以包含最新 K 线的分布最多等一分钟多才出来。数据源只给最近一段成交时，范围里有更早的 K 线就画不出来，提示缩小到最近的 K 线。
  - 最多算 3 天的成交：可见范围超过的不画，写「范围太大」；按交易日时只画最近 3 天，更早的那些天这样标。秒级周期不能按主动买卖拆分（成交按分钟保存）。
  - 接口里是 `params: { split: 1 }`（`0` 是 K 线涨跌），线条是 `buy`、`sell`、`poc`；存在状态里每张图的 `indicators` 的 `params` 里。商业授权码包括它。
- **订单流**一组是商业版订单流按逐笔成交的主动方算的 3 个指标，各在自己的副图里，和别的指标一样有图例数值和按钮、设置窗口、能移到别的窗格、存进布局和指标模板：
  - **VD 成交量差**（Volume Delta / 出来高デルタ / 거래량 델타）：每根 K 线一根蜡烛，从 0 到这根的主动买入量减主动卖出量，最高、最低是按分钟累加的差额到过的最高、最低；0 有一条参考线。图例写 O、H、L、C 四个值。
  - **CVD 累计成交量差**（Cumulative Volume Delta）：从每个周期开始累加成交量差，每根蜡烛从这根开始时的累计到结束时的累计，最高最低按分钟；每个周期从 0 重新算起。周期是参数**重新计算**（`anchor`，和 VWAP 的同名参数一样的选项和名称）：**每日**（`0`，默认，品种交易日历的交易日）、**每周**（`1`）、**每月**（`2`），按品种的交易日历切分；图例在名字后面写上它（`CVD 每周`）。没有每季、每年：超过 30 天的成交。一根 K 线算在它开始的周期里，K 线和周期一样长或更长时（日线选每日）每根从 0 开始。
  - **UDV 主动买卖量**（Up/Down Volume）：主动买入量画在 0 上面、主动卖出量画在 0 下面（主题的涨、跌色），差额画一个「—」。
  - 蜡烛和柱状图一样按涨跌着色，样式页里写「颜色随涨跌」；设了颜色就全用这个颜色。没有参数。
  - 成交和成交量轨迹、按主动买卖拆分的成交量分布共用一份，只取屏幕上的 K 线、最新的先取，只要每分钟的买卖量，最多 30 天的成交（日线最多 30 根；CVD 从它的周期的开始取起，开始在 30 天以外的周期不画、写「范围太大」，比如 31 天的月份的最后一天）。一根 K 线的每一分钟成交都到齐才画；CVD 要这个周期从开始到这根结束的每一分钟都到齐，有一分钟没有，这个周期后面都不画，**绝不画从中途算起的累计**。没画的 K 线在副图里写「加载中」「无成交数据」「加载失败」「范围太大」，图的左下角写一句原因；秒级周期和砖形图、卡吉图这类不按时间的 K 线不画，也写明。图刚打开时最新那根要等当前这一分钟走完、从历史补全才画出来。
  - 实时成交来了只重读最新一分钟、只重算最新一根；回放时只算已放出的 K 线。
  - 它们读的成交只有图上有，后台盯盘的提醒没有，所以不能在它们上面加提醒（图例上没有铃铛，提醒窗口里不列）。
  - 接口里是 `addIndicator('CVD')`；数据源没有 `getTradeMinutes()` 时窗口里不列、`addIndicator` 报错。商业授权码包括它们。

- **大单**（LARGETRADES）和**订单簿热力图**（BOOKHEATMAP）在「订单流」组里，是商业版订单流画的。它们和成交量分布一样画在主图上，没有自己的窗格、不能设提醒；一张图上同一种只画第一个显示着的。图例里没有它们这一行，在「图表元素」面板里列出、点开设置。
  - **大单**：主图 K 线上面的气泡，在成交的时间（放在它那根 K 线的宽度里，K 线开始在左边）和价格上，面积按成交额（价格 × 数量），颜色按主动方（默认主题的买、卖色）。参数：**大单标准**（`threshold`）选**自动**（`0`，屏幕上的 K 线里成交额最大的「个数」笔）或**最低成交额**（`1`，成交额不低于「最低成交额」的每一笔，按计价货币）；**个数**（`count`，默认 50，1 到 500）；**最低成交额**（`minValue`，默认 100000）；**大小**（`size`，最大的气泡半径多少像素，默认 18，4 到 60）。线条是 `buy`、`sell`。「图表元素」里写个数（自动）或 `≥ 最低成交额`。成交和成交量轨迹共用一份（同一品种的几张图也共用）：数据源有 `getTradeMinutes()` 时补出图打开以前的（每分钟成交额最大的 32 笔），没有时只有打开以后的；一根 K 线的成交到齐了才画它的大单，最多取最近 3 天的成交，秒级周期不画（成交按分钟保存），回放时只画已放出的；画不出来的原因写在图的左下角。成交按分钟存时每分钟只留成交额最大的 32 笔：一分钟里比设的下限值钱的成交多于 32 笔时，实际画的下限会抬高到那一分钟留下的最小一笔以上，保证比画的下限值钱的成交一笔不漏（`chart.largeTrades.status().threshold` 是实际画到多小）。
  - **订单簿热力图**：主图 K 线后面，每一列像素是它那段时间的平均挂单量，每一行像素是那些价格里挂单最多的一行，买单用主题的买色、卖单用卖色，越多越不透明（满格是屏幕上格子的 99% 分位数）；右边沿画当前的订单簿（最长的一行占绘图区宽度的 12%）。参数：**不透明度**（`opacity`，满格时的不透明度，百分比，默认 80）；**当前订单簿**（`profile`，`1` 显示、`0` 隐藏）。线条是 `buy`（买单）、`sell`（卖单）。热力图从订阅订单簿开始才有（交易所不给过去的），断了的那几秒空着；还没有订单簿时图的左下角写「从现在起开始记录」，断了时写「订单簿断了」。
  - 接口里是 `addIndicator('LARGETRADES', { params: { threshold: 1, minValue: 250000 } })`、`addIndicator('BOOKHEATMAP', { params: { opacity: 60 } })`；指定窗格会报错。商业授权码包括它们。

**指标模板**在指标窗口左边的「指标模板」里：填一个名称点保存，当前图上的指标连同参数、线条和参考线设置就存成一个模板（同名的提示后替换）；点一个模板，当前图的指标换成模板里的（原来的指标去掉，比较品种和画线不变）；垃圾桶删除模板。模板按名称排列，搜索框也能按名称找。模板存在状态的 `indicatorTemplates` 里（`[{ name, indicators }]`，`indicators` 和每张图的 `indicators` 格式一样），所有图共用，跟着 `storage` 或 `getState()` 走。
