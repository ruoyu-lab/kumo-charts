# 图表类型

顶栏的图表类型菜单按组排列，每种在中、英、日、韩里各有名字，后面是我们自己的几种 K 线；接口和状态里用的是左列的名字：

| 类型                                                  | 说明                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ohlc`、`candles`、`hollow-candles`、`volume-candles` | 美国线、K线图、空心K线图、成交量蜡烛（宽度按成交量）                                                                                                                                                                                                                                                                                                           |
| `line`、`line-markers`、`step-line`                   | 线形图、带标记线、阶梯线                                                                                                                                                                                                                                                                                                                                       |
| `area`、`hlc-area`、`baseline`                        | 面积图、HLC区域、基准线                                                                                                                                                                                                                                                                                                                                        |
| `columns`、`high-low`                                 | 柱状图（从窗格底部长起，按比前一根涨跌着色）、高-低                                                                                                                                                                                                                                                                                                            |
| `footprint`、`tpo`                                    | 成交量轨迹、时间价格机会（商业版的订单流，见下面的「成交量轨迹和时间价格机会」）：每根 K 线每个价位的主动买入和卖出量；每个交易日按 30 分钟一个字母的市场轮廓                                                                                                                                                                                                  |
| `heikin-ashi`、`range`                                | 平均K线图、范围图，由当前周期的 K 线构建；范围图每根的高低差按最近 14 根已收盘 K 线的平均真实波幅自动定，取整方式和砖形图一样                                                                                                                                                                                                                                  |
| `renko`                                               | 砖形图：砖块对齐到砖块大小的整数倍，超出上一块一个砖块大小生成新砖，反转要两个。设置：`method` 是「大小按」，`atr`（默认，最近 `atrLength` 根的 ATR，默认 14）、`traditional`（固定 `box`）或 `percentage`（最新价的 `percentage`%，默认 1）；`source` 是 `close`（默认，收盘价）或 `ohlc`（开高低收）；`wicks` 是影线（默认开，设置里在颜色的「影线」那一行） |
| `line-break`                                          | 新价线：收盘价越过最近 `lines` 根线（默认 3）的最高或最低时，画一根新线                                                                                                                                                                                                                                                                                        |
| `kagi`                                                | 卡吉图：按收盘价画线，沿原方向走时一直延伸，从极值回撤「反转格数」时转向；线向上越过前一个肩部起变粗（阳线，涨的颜色），向下跌破前一个腰部起变细（阴线，跌的颜色）。设置：`method` 是「大小按」，`atr`（默认，最近 `atrLength` 根的 ATR，默认 14）、`traditional`（固定 `reversal`）或 `percentage`（最新价的 `percentage`%，默认 1）                          |
| `point-figure`                                        | 点数图：X 列和 O 列，格子大小同样按 `method` 定（`atrLength`、固定 `box`、`percentage`）；`reversal` 是换列要反向走的格数（默认 3），`source` 是 `close`（默认，收盘价）或 `hl`（最高最低价），`oneStepBack` 是「单格转向」（反转 1 格时，只有一格的列在同一列里转向）                                                                                         |
| `volume`、`turnover`                                  | 等量、等额 K 线：每根攒够 `volume`（成交量）或 `turnover`（成交额）收线。默认 `null`，按当前周期平均每根的量；`input` 是 `bars`（默认，合并当前周期的整根 K 线，有历史，周期越短越细）或 `trades`（实时成交，见下）                                                                                                                                            |
| `tick`                                                | 逐笔 K 线：每 `count` 笔成交一根（默认 100），从实时成交构建                                                                                                                                                                                                                                                                                                   |
| `imbalance`、`runs`                                   | 不平衡 K 线、游程 K 线（商业版的信息驱动 K 线），从实时成交构建：`ticks` 是开始时预期每根的成交笔数（默认 200），`measure` 是每笔的权重，`tick`（笔数，默认）、`volume`（成交量）或 `turnover`（成交额）                                                                                                                                                       |

设置在「图表设置 → K 线」的最上面：构建自哪里、每根的大小（几档常用的大小，或者自己填）、每笔的权重；砖形图、卡吉图和点数图是上面那些设置，按 ATR 或百分比定大小时旁边写着当前算出的大小，换成「传统」时先填上当前算出的大小（而不是固定的 1 或 3，大多数品种用不了），再自己改。每种类型的设置分别存在状态里（`ChartView.barSettings`），切回来时照旧。

砖形图、卡吉图和点数图按下面的规则构建，BTCUSDT、ETHUSDT 等日线、周线算出的每一块砖、每一根线、每一列都核对过：

- 砖形图第一个价格落在网格的哪一格，就从那一格开始；砖块的时间是生成它的那根 K 线，成交量是从上一批砖块以来的总和，同一个价格生成的几块平分。按开高低收时，上涨的 K 线依次走开、低、高、收，下跌的走开、高、低、收，每个价格占四分之一的成交量。影线伸到两批砖块之间的最高或最低价，只在价格朝反方向超出这块砖的开盘价一个砖块以上时才有。

- 卡吉图的第一条线从第一个收盘价开始，等收盘价离它达到反转的幅度才画出；每条线一根，开盘是起点，收盘是极值，时间是开始它的那根 K 线，成交量是从那根到极值所在那根的总和。
- 点数图的格子对齐到格子大小的整数倍，换列时从上一列最后一格错开一格开始；每列一根，开盘是第一个格子的价位，收盘是最后一个。
- 按 ATR 或百分比定的大小取整到 10 的最高次幂的一半的整数倍（2137 → 2000，820 → 800）。按 ATR 定时取到最后一根已收盘的 K 线（和 ATR 指标一样的算法；正在走的那根不算：ATR 长度填 1 时大小正好是前一天的真实波幅）。要固定的大小，用「传统」自己填。
- 砖形图、新价线、卡吉图和点数图的最后一根停在砖块、线或格子上，不在实时价上：价格轴上最新价线和标签照旧在最后一根上，旁边另有一个颜色浅一些的标签标出实时价（高于最后一根的收盘用涨的颜色，低于用跌的颜色）。

周期和图表类型在顶栏是同一个样子：没有点亮的项时，一个按钮写着当前的周期（图表类型只显示图标，名称在鼠标经过的提示里），后面一个淡色的小箭头，点它打开菜单。点亮了的话，依次是点亮的项（图表类型只显示图标）、最近一次选的没点亮的项、单独的小箭头按钮：最近选的那项在切到点亮的项时仍然留着，点一下直接切回去，不用打开菜单；只有点小箭头才打开菜单。菜单每一行经过时行尾出现星标（点亮的一直显示）。点亮的类型存在状态的 `favoriteChartTypes` 里，接口是 `setFavoriteChartTypes(types)`。

```ts
chart.setChartType('tick', { count: 500 });
chart.setChartType('volume', { volume: 1000, input: 'trades' });
chart.setChartType('imbalance', { ticks: 300, measure: 'volume' });
chart.setChartType('volume', { volume: null }); // 回到平均每根的量
chart.setChartType('renko', { method: 'percentage', percentage: 1, source: 'ohlc', wicks: true });
chart.setChartType('kagi', { method: 'traditional', reversal: 2500 });
chart.setChartType('point-figure', { method: 'atr', atrLength: 20, reversal: 3, source: 'hl' });
```

**从实时成交构建的 K 线**（`tick`、`imbalance`、`runs`，以及 `input: 'trades'` 的等量、等额 K 线）只用 `LiveListener.trades` 推来的成交，界面上都写明了：

- **没有历史**：`getBars()` 只给 K 线，所以这些 K 线从这张图打开（或换品种）以后收到的成交开始。收到第一笔之前图上写着「正在等待实时成交」，之后左下角写着从几点开始。
- **断线有缺口**：数据源重连后补的通常是 K 线，不是断线期间的成交，所以时间 K 线完整，从成交构建的 K 线在那段时间缺一块。
- **一笔是数据源推送的一笔**：数据源推送的是归集成交（同一笔主动单的多次成交合成一笔，如币安 U 本位永续）时，逐笔 K 线每根包含的真实成交更多。
- 数据源只推 K 线、不推成交时会一直等待。
- 它们和周期无关：顶栏上没有周期高亮，点一个周期就回到那个周期的蜡烛图（`setTimeframe()` 也一样）。图表保留最近 100,000 笔成交，更早的成交丢掉后，用它们构建好的 K 线仍然保留。

## 成交量轨迹和时间价格机会

两种都在菜单里柱状图、高-低之后，平均K线图之前，名字是：成交量轨迹 / Volume footprint / 出来高フットプリント / 볼륨 풋프린트，时间价格机会 / Time Price Opportunity / タイム・プライス・オポチュニティ / 시간 가격 기회。设置在「图表设置 → K 线」的最上面；接口是 `setChartType('footprint', { … })`、`setChartType('tpo', { … })`，字段如下。

**成交量轨迹**（`footprint`）：每根 K 线旁边，按价格分行，左边一列是主动卖出量，右边一列是主动买入量，中间是一根细的 K 线；下面是两列各自的合计，再下面一个小框写 Delta（买减卖）和总量。

| 字段                                         | 默认值         | 说明                                                                                                                                                                      |
| -------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rowSize`、`atrLength`、`ticksPerRow`        | `auto`、14、10 | 行大小：`auto` 是最近 `atrLength` 根 K 线的平均真实波幅的五分之一，取整到 tick（换品种、换周期时重算，设置里写着当前算出的行大小）；`manual` 是每行 `ticksPerRow` 个 tick |
| `display`                                    | `cluster`      | 显示：`cluster` 群集（每格一样宽），`profile` 分布图（格子按量的大小从 K 线向外长）                                                                                       |
| `type`                                       | `buy-sell`     | 类型：`buy-sell` 买入和卖出，`delta` 一列买减卖，`total` 一列总量，`ladder` 阶梯（每行只给大的一边上色）                                                                  |
| `gradient`、`sell1`…`sell4`、`buy1`…`buy4`   | 开、跟主题     | 背景按量分四档深浅（在这根 K 线自己一边的最小到最大之间按四分之一分档）；关掉时用第二档。颜色 `null` 是主题的涨跌色调出的四档                                             |
| `valueArea`、`valueAreaPercent`              | 开、70         | 价值区域：上下沿画虚线                                                                                                                                                    |
| `poc`、`pocColor`                            | 开、主题文字色 | 控制点：量最大的一行整行填色                                                                                                                                              |
| `summary`                                    | 开             | 显示摘要信息：两列合计和 Delta、总量的小框                                                                                                                                |
| `imbalance`                                  | 300            | 不平衡（%）：某行的主动买入量至少是下一行主动卖出量的 300%（对角比较）为买方不平衡，某行的主动卖出量至少是上一行主动买入量的 300% 为卖方不平衡                            |
| `highlight`、`buyHighlight`、`sellHighlight` | 开、跟主题     | 突出显示：不平衡的格子外侧一条竖线，买方在右、卖方在左                                                                                                                    |
| `stacked`、`stackedLevels`                   | 关、3          | 堆叠水平：连续 3 行以上同一方向的不平衡，从这根 K 线向右画一个区域，直到价格回到这个区域                                                                                  |

成交量轨迹要每一笔成交和它的主动方，不能从 K 线推出来：

- **数据从哪来**：历史用数据源的 `getTradeMinutes()` 给的每分钟每个价位的量，打开以后用推送的成交（`side` 必须有，没有的成交不算）。只取屏幕上的 K 线，从最新的往前取，一次最多 6 小时、两个请求同时；同一个品种的几张图共用一份。
- **不显示错的数**：一根 K 线只有它的每一笔成交都到齐了才画，否则 K 线下面写「加载中」「无成交数据」或「加载失败」（稍后自动重试），图的左下角写一句原因。走完的 K 线还会和数据源的 K 线成交量核对：对不上（比如断线时漏了推送的成交）就重新取一次；有历史的重新取到的和 K 线相差在千分之一以内就用它（有的平台偶尔把一笔归集成交的最后几笔算到下一分钟），差得多或者没有历史的就标成「无成交数据」。
- **能看多远**：看数据源的 `getTradeMinutes()` 能给多远。没有它或只给最近一批时，成交量轨迹基本从图打开的那一分钟起（那一分钟本身要等它走完、能取到时才补全，取不到就一直是「无成交数据」）。
- **回放**：只用到回放位置为止的成交。秒级周期不支持（成交按分钟保存）。一根 K 线超过 2000 行时不画，提示调大每行 tick 数。

**时间价格机会**（`tpo`，市场轮廓）：价格是一条收盘价的线；每个交易日一个轮廓，画在这一天的开头，每 30 分钟一个字母（A 到 Z、a 到 z，再从 A 开始），这半小时到过的每一行都放一个；右边是这一天每行的成交量。

| 字段                                     | 默认值           | 说明                                                                                                                                          |
| ---------------------------------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `period`、`periodUnit`                   | 1、`D`           | 时段：几天（`D`）、几周（`W`）、几个月（`M`）一个轮廓，按品种的交易日历                                                                       |
| `block`                                  | `30m`            | 块大小：`5m` `10m` `15m` `30m` `1h` `2h` `4h`                                                                                                 |
| `rowSize`、`ticksPerRow`                 | `auto`、10       | 行大小：`auto` 把最近 300 根 K 线的价格范围分成 80 行，取整到 5、50、500…的倍数；`manual` 每行 `ticksPerRow` 个 tick                          |
| `valueArea`                              | 70               | 价值区域（%，按字母个数算）                                                                                                                   |
| `color1`…`color4`                        | 粉、绿、青、紫   | 渐变色：A、N、a、n 是这四种颜色，中间每 13 个字母从一种过渡到下一种                                                                           |
| `blocks`、`letters`、`opacity`、`expand` | 开、开、44、关   | 块、字母（格子太小时不写）、VA 以外的不透明度（%）、按块拆分（每个字母放在它的时间位置上）                                                    |
| `poc`、`vah`、`val`                      | 开               | 控制点（字母最多的一行，整行填色）和价值区域上下沿的虚线，左边带标签                                                                          |
| `nakedPoc`、`nakedPocColor`              | 关、控制点的颜色 | 未回补的控制点：此前最多 20 个周期的轮廓里，之后再没有 K 线碰到过的控制点，从轮廓右边画一条虚线到图的右边；之后有 K 线碰到，线就不再画        |
| `poorHigh`、`poorLow`、`singlePrints`    | 关               | 弱高、弱低（最高、最低一行不止一个字母）画线；单个绘制（中间只有一个字母的行）画成横跨这一天的色带                                            |
| `midpoint`、`open`、`close`              | 关               | TPO 中点、开盘价、收盘价的标签                                                                                                                |
| `initialBalance`、`initialBalanceBlocks` | 开、2            | 初始平衡范围（IBR）：前 2 个块（第一个小时）的范围，在轮廓左边画一条竖线；字母按块在时段里的时间排，没有成交的块也占一个字母                  |
| `volumeProfile`、`volumeValues`          | 开、关           | 每行的成交量（每个块的量按它覆盖的长度分到各行，按块算，图表周期不影响），价值区域里的颜色深一些；`volumeValues` 写上每行的数值和这一天的总量 |
| `volumeVah`、`volumeVal`、`volumePoc`    | 关、关、开       | 成交量的价值区域上下沿、控制点画线（控制点默认红色），颜色 `volumeLineColor`、`volumePocColor`                                                |
| `volumePlacement`                        | `left`           | 位置：每行从成交量那块地方的左边（`left`）还是右边（`right`）长出                                                                             |

字母由图表自己的 K 线构建：选了时间价格机会时，图表取的 K 线换成能同时合成当前周期和块大小的那种（比如日线图配 30 分钟块就取 30 分钟线），所以历史、实时和回放都和 K 线一致；数据源没有能合成块的 K 线时图上写明。控制点有几行一样多时取离轮廓中间最近的（再一样取上面的），价值区域从控制点起每次比较上面一行和下面一行，加字母多的一行（一样多时取离控制点近的，再一样取上面的），加上下一行就超过 70% 时停。

这些还没有做：按某个字母拆分轮廓、和前一个合并，各条线的「延长到价格回来」，按交易时段（盘前、盘中、盘后、自定义）分开的轮廓，摘要信息表格，以及在这些水平上的提醒；成交量轨迹的摘要信息表格和不平衡、Delta 的提醒也没有做。
