# Kumo Charts 商业版

Kumo Charts 商业版是建立在开源 [Kumo Charts](../../zh-CN/index.md) 上的商业组件，买一份[商业授权](license.md)使用。核心是**专业图表**：一个带全套工具的看盘图表，接上自己的行情数据就能嵌进网页，Vue、React 和普通网页都能用。

```ts
import { createProChart } from '@kumo-charts/pro-chart';

const chart = createProChart(document.getElementById('chart')!, {
  datafeed: myDatafeed,
  symbol: '600519.SH'
});
```

从[快速开始](getting-started.md)读起。

## 包含什么

- **专业图表**（`@kumo-charts/pro-chart`）：顶栏的品种搜索、比较品种、周期、图表类型、指标和指标模板、回放、撤销重做、截图和导出图表数据，左边的画线工具，多图布局，右键菜单，图表设置和指标设置窗口，以及价格、指标和画线的[提醒](alerts.md)。顶栏可以整个去掉换成页面自己的，页面的自选列表可以接到品种搜索的星标上，按钮、右键菜单、指标和画线工具都能加页面自己的。
- **订单流**：成交量轨迹、时间价格机会（TPO）两种[图表类型](chart-types.md)，成交量差、累计成交量差、主动买卖量三个[指标](indicators.md)，大单和订单簿热力图，以及按主动买卖拆分的成交量分布。
- **信息驱动 K 线**：不平衡 K 线和游程 K 线，从实时成交构建。
- **公式指标**：国内看盘软件写法的[公式](formula.md)直接变成逐笔实时计算的指标。

这些都在专业图表里，一个商业授权码全部包含。

## 先试再买

本机开发服务器上的页面（`localhost`、`127.0.0.1` 这些）不需要授权码，也没有水印，可以完整地试。放到正式网站或应用里时，没有授权码的图表左下角显示「Kumo Charts 商业版 · 未授权，仅供试用」。授权分个人和公司两档，在 [kumocharts.com](https://kumocharts.com/zh-CN/#pricing) 购买，付款后马上拿到授权码，规则见[授权](license.md)。

## 界面一览

图上点右键：重置图表视图（Alt+R，Mac 上是 ⌥R）、复制价格、在这个价格添加提醒（一点就加上）、添加提醒…（Alt+A，打开提醒窗口）、从这根 K 线开始回放、添加指标、隐藏或删除画线、删除提醒、截图、图表设置；在画线或提醒线上点右键是它们自己的操作（画线：在它的线上添加提醒…、复制、锁定、隐藏、删除；提醒线：编辑提醒…、暂停、删除，双击提醒线也打开它）。价格轴上点右键：在这个价格添加提醒…、重置价格刻度、自动缩放、反转坐标（Alt+I）、常规、百分比（Alt+P）、指数化到 100、对数（Alt+L），以及最新价的标签、线和收盘倒计时，每张图各自保存；副图的价格轴只有重置和自动缩放。时间轴上点右键可以重置时间刻度。

多图布局在顶栏右边：一张、左右两张、上下两张，三张的两种排法：左一大右两小、左两小右一大，四张，以及六张的四种排法：两行三列、三行两列、左一大右五小、上一大下五小。可以让其他图跟着当前图切换品种、切换周期、移动十字线、对齐时间（周期默认不跟，各图看不同周期）。图之间的分界都可以拖动调整大小，每张图至少留 200×120 像素，地方不够时平分；双击分界，这一方向的分界回到默认位置。

时间轴右下角（价格轴下面）显示图上时间的时区，如 `UTC+8`。点开可以选交易所时间（品种交易日历的时区；数据源没给日历的品种按全天候 UTC，如各平台的加密货币）、UTC、本地时间，或主要城市的时区，每项带着现在的 UTC 偏移。选择存在状态里，所有图一起用；只改显示的时间，K 线照旧按品种的交易日历切分。回放小窗里的时间也按这个时区。

选中一条画线，它旁边会浮出常用的工具栏（颜色、线宽、线型、复制、锁定、删除）；点工具栏上的齿轮或双击画线，打开画线设置窗口，分四页：样式（线条、填充、向左向右延伸、箭头、斐波那契各档的数值、颜色和显示）、文字（内容、颜色、字号、粗体斜体、对齐和位置）、坐标（每个点的时间和价格，可以精确输入）、可见周期（只在哪些秒、分钟、小时、日、周、月周期上显示）。改动随输入、随拖动生效，撤销时一次编辑算一步：在一个输入框里连着打的字、拖一次不透明度滑块，一次撤销就整个退回。每种工具记住用户上次给的样式，新画的线直接用它；文字画线双击仍是在图上直接编辑。

回放的控制是浮在图上的小窗：按住左端的点拖到任意位置，位置会保存，双击放回原处。选回放起点时，指针所在 K 线右边、回放会隐藏的部分变淡。

多图布局里，同一个品种的图一起回放：点回放后，显示这个品种的每张图都可以选起点，鼠标在哪张图上，哪张图就显示要隐藏的部分；在哪张图上点，就从哪张图开始，它成为当前的图，回放控制按它的周期走，其他同品种的图跟到同一时间。周期比它大的图改用它那么细的 K 线合成，正在走的那根 K 线跟着长出来，看不到之后的价格；换数据要一会儿，这期间那张图先空着。别的品种的图照常显示实时行情。在任何一张同品种的图上退出回放，都一起回到实时。

## 截图和导出数据

顶栏右边的相机按钮是一个菜单：

- **下载图片**（Alt+S）：当前图存成 PNG，文件名如 `BTCUSDT-1h.png`。
- **复制图片**（Alt+Shift+S，Mac 上 ⌥⇧S；Ctrl+Shift+S 在有的浏览器里是它自己的截图）：当前图的图片放进剪贴板，可以直接粘贴到聊天、文档里。浏览器不让网页往剪贴板放图片时（较旧的浏览器，或不是 https 的网页），改为下载这张图片，并提示一句。

导出数据默认不显示；`features: { dataExport: true }` 打开后放在布局的菜单里（顶栏右边多图布局的按钮，最后一项）：

- **导出图表数据…**：选图（多图布局时）和时间格式，导出 CSV，文件名如 `BTCUSDT-1h.csv`。

CSV 里是图上已加载的每根 K 线，按图显示的样子：当前周期、当前图表类型（比如平均 K 线就是平均 K 线的值），回放时到回放的位置。每行依次是 `time`、`open`、`high`、`low`、`close`、`volume`，然后是显示中的每个指标在图例里列出的每条线（隐藏的指标和线不导出），列名是线的英文名称（不随界面语言变），如 `MA9`、`Signal line`，重名时后面带上指标代码，如 `MA9 (VOL)`。指标的数值和图上的、和图表库的 `computeIndicator()` 对同样 K 线算出的完全一样，按算出的写全（浮点运算末尾可能有误差，如 `82080.56000000011`，四舍五入到图上的小数位就和图例一样）；指标还没有数值的 K 线（如 MA20 的前 19 根）留空。成交量分布这类不是每根 K 线一个值的不导出，比较品种也不导出。

时间格式有两种：**ISO 时间**按图表选的时区写，带当时的时区偏移，如 `2026-10-22T08:00:00+08:00`（UTC 写 `Z`，有夏令时的时区按各自日期的偏移）；**UNIX 时间戳**以秒计，如 `1792627200`（逐笔 K 线这类有毫秒的写成小数）。

`features: { screenshot: false }` 去掉相机按钮；关了 `multiChart` 而导出开着时，布局的按钮只用来导出（表格图标）。不打开 `dataExport`，页面也可以用 `openDialog('exportData')` 打开导出窗口，比如放进自己的菜单。
