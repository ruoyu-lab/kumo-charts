# オプション

| オプション               | 説明                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `datafeed`               | 相場データ。必須                                                                                                                                                                                                                                                                                                                                                   |
| `symbol`                 | 初めて開いたときに表示する銘柄。必須。以降はユーザーが最後に見ていた銘柄                                                                                                                                                                                                                                                                                           |
| `timeframe`              | 初めて開いたときの時間足。デフォルトは `15m` で、提供する時間足に `15m` がないときは最初のもの                                                                                                                                                                                                                                                                     |
| `timeframes`             | 提供する時間足。デフォルトは `1m 3m 5m 15m 30m 1h 2h 4h 6h 12h 1D 1W 1M`（`DEFAULT_TIMEFRAMES`）。初めて開いたときはトップバーに `5m 30m 4h 1D` を直接表示し、残りは時間足メニューに入ります。データフィードが合成できないものは自動的に除かれます                                                                                                                 |
| `indicators`             | 初めて開いたときのインジケーター。デフォルトは `MA` と `VOL`                                                                                                                                                                                                                                                                                                       |
| `theme`                  | `light`（デフォルト）または `dark`。ページが決めます                                                                                                                                                                                                                                                                                                               |
| `language`               | `zh`（デフォルト）、`en`、`ja`、`ko` のいずれかで、ページが決めます（`LANGUAGES` はそれらとそれぞれの名前を並べ、`isLanguage(value)` はある値がそのいずれかかを確かめます）。日付と数値は `zh-CN`、`en-US`、`ja-JP`、`ko-KR` の慣習で書きます（`LOCALES`）                                                                                                         |
| `upColor`                | `red` で上昇が赤・下落が緑。デフォルトは `green`                                                                                                                                                                                                                                                                                                                   |
| `accentColor`            | ボタンや選択状態のメインカラー。たとえばブランドカラー                                                                                                                                                                                                                                                                                                             |
| `timeZone`               | ユーザーが自分でタイムゾーンを選ぶまで時間の表示に使うタイムゾーン。`Asia/Shanghai` のような値か、`exchange`（銘柄ごとに取引カレンダーのタイムゾーン）。デフォルトはブラウザのタイムゾーン。ユーザーが時間軸の右下で選んだあとは、ユーザーの選択（状態に保存）に従います                                                                                           |
| `brand`                  | `{ name, logo, href }`：左上の名前、ロゴ画像のアドレス、クリックしたときの移動先。`name` だけなら名前だけを表示し、`name` も `logo` もなければ KumoChart のマークを表示し、`brand` がなければ左上には何も表示しません                                                                                                                                              |
| `features`               | 不要な部分をオフにします。下の一覧を参照                                                                                                                                                                                                                                                                                                                           |
| `lockedLinks`            | ページが固定する連動。たとえば `{ symbol: true }` で 1 つのレイアウトのチャートが常に同じ銘柄を表示します。固定した連動は保存された状態や `setLinks()` で変わらず、レイアウトメニューにも出なくなります。デフォルトではどれも固定しません                                                                                                                          |
| `messages`               | 画面の文言を差し替えます：`{ ja: { indicators: 'テクニカル指標' } }`                                                                                                                                                                                                                                                                                               |
| `themes`                 | テーマごとの色。画面のデザイン変数とチャート自体の色です。[「色とフォント」](appearance.md)を参照                                                                                                                                                                                                                                                                  |
| `fontFamily`             | 画面と軸のフォント。CSS の `font-family` の書き方です                                                                                                                                                                                                                                                                                                              |
| `buttons`                | ページ独自のボタン。トップバーか描画ツールバーに置きます。[「独自のボタン」](page-items.md)を参照                                                                                                                                                                                                                                                                  |
| `contextMenu`            | ページ独自の右クリックメニュー項目。[「右クリックメニュー」](page-items.md)を参照                                                                                                                                                                                                                                                                                  |
| `crosshairLines`         | 価格軸上のクロスヘアの価格ラベルの下に、テキストの行を追加します。たとえば現在値との差。引数は `{ chart, symbol, price }`（ポインターがある足の領域の価格）で、テキストのリストを返します。ポインターが動くたびに呼ばれるので高速である必要があります                                                                                                              |
| `watchlist`              | ページのウォッチリストにある銘柄の id。銘柄検索でそれらの星印が点灯し、ユーザーが星印をクリックすると `watchlistStar` が発火します。[「ウォッチリスト」](page-items.md)を参照。デフォルトは `null` で、星印はありません                                                                                                                                            |
| `drawingTools`           | 描画ツールバーにどのツールをどの順で置くか。[「描画ツール」](drawings.md)を参照                                                                                                                                                                                                                                                                                    |
| `drawingStyles`          | ページが描画ツールに与えるスタイル。たとえばフィボナッチのレベルをどちらの端から数えるか。ユーザーが自分で変えたスタイルはその上にかぶさります。[「描画ツール」](drawings.md)を参照                                                                                                                                                                                |
| `drawingBarItems`        | 描画を選択したときに浮かぶバーに何をどの順で置くか：組み込みの項目、スタイルの切り替え（`{ field: 'extendRight' }` など）、ページ独自のボタン。[「2 つのバーを変える」](drawings.md)を参照                                                                                                                                                                         |
| `drawingToolbarControls` | 描画ツールバーのツール以外のボタン（クロスヘア、マグネット、連続描画、お気に入り、非表示、すべて削除）のうちどれを残すか。[「2 つのバーを変える」](drawings.md)を参照                                                                                                                                                                                              |
| `customDrawings`         | ページ独自の描画ツール。組み込みのものと一緒に描画ツールバーに置きます。[「カスタム描画ツール」](custom-drawings.md)を参照                                                                                                                                                                                                                                         |
| `customIndicators`       | ページ独自のインジケーター（独自のアルゴリズム、または数式で書いたもの）。組み込みのものと一緒にインジケーターウィンドウに並びます。[「カスタムインジケーター」](custom-indicators.md)を参照                                                                                                                                                                       |
| `storage`                | ユーザーのレイアウト、各チャート、描画、アラートの保存先。デフォルトはブラウザの `localStorage`（キー名 `kumochart-pro-chart`）で、`browserStorage(key)` でキー名を変えられ、独自のストレージにもできます（[「状態の保存」](storage.md)を参照）。`null` を渡すと保存しません                                                                                       |
| `licenseKey`             | 商用ライセンスキー。チャート内のフットプリント、タイム・プライス・オポチュニティ、オーダーフローのインジケーター、大口約定、板情報ヒートマップ、情報駆動型の足、数式インジケーターを含みます。ライセンスキーがないとチャートの左下に「ライセンス未登録」のウォーターマークが出ます。不要なのは自分のパソコンでの開発だけです（[「ライセンス」](license.md)を参照） |
| `appId`                  | デスクトップアプリ・モバイルアプリのアプリ ID。逆ドメイン形式で、`com.acme.charts` のように書き、`licenseKey` と一緒に渡します。ドメイン名のないページはこれでライセンスし、Web サイトはドメインだけで判定します（[「ライセンス」](license.md)を参照）                                                                                                             |

`features` の切り替え：`topBar`（トップバー、下を参照）、`symbolSearch`（銘柄検索。データフィードが検索できるときはデフォルトでオン）、`compare`（銘柄比較。同じくデータフィードが検索できる必要があります）、`chartTypes`（チャートタイプ）、`indicators`（インジケーター）、`volumeProfile`（価格帯別出来高）、`drawings`（描画）、`replay`（リプレイ）、`alerts`（価格・インジケーター・描画のアラート）、`history`（描画の元に戻す・やり直す）、`screenshot`（スクリーンショット：画像のダウンロードまたはコピー）、`dataExport`（チャートデータのエクスポート）、`multiChart`（マルチチャートレイアウト）、`shortcuts`（キーボードショートカット。[「キーボードショートカット」](shortcuts.md)を参照）。銘柄検索、銘柄比較、チャートデータのエクスポート以外はデフォルトでオンです。切り替えは画面だけを対象にします（`alerts` は例外で、オフにすると既存のアラートも描かず、監視もしません。[「アラート」](alerts.md)を参照）。たとえば `indicators` をオフにするとユーザーにはインジケーターのボタンが見えませんが、ページは `addIndicator()` でインジケーターを追加できます。`compare` をオフにしても、ページは `addComparison()` で銘柄を比較できます。

描画にはさらに 2 つの小さな切り替えがあります：`drawingToolbar`（左側の描画ツールバー）と `drawingBar`（描画を選択したときに浮かぶバー）で、どちらもデフォルトでオンです。オフにしても描画機能はそのままで、ページは `chart.drawingTools` で独自のものを置けます。[「自前の描画ツールバー」](drawings.md)を参照してください。

**トップバー**：`topBar` をオフにすると、トップバー全体（銘柄、時間足、チャートタイプ、インジケーター、レイアウト、リプレイ、ページのボタン）が表示されなくなり、チャートがコンテナいっぱいに広がります。ページは独自のバーを置き、メソッドで操作します：`setSymbol()`、`setTimeframe()`、`setChartType()`、`setLayout()`、`openDialog('symbolSearch')`、`openDialog('indicators')` など。状態の変化はイベント（`symbolChange`、`timeframeChange`、`layoutChange`……）から読み取ります。キーボードショートカット、右クリックメニュー、各ウィンドウはそのまま使えます。

オプションの書き間違い（オプション名や `features` の切り替え名のつづり間違い、`messages` にない文言、テキストもアイコンもないボタン、描画ツール名のつづり間違い、存在しない色変数名、提供する時間足にない `timeframe`、`indicators` にないインジケーター）があると、`createProChart()` はその場でエラーを投げ、どこが違うか、何を書けるかを示します。型を書いていないページでフィールド名を 1 つ間違えても、黙って効かないということはありません。

## 表示後に変える：applyOptions

テーマ、言語、色、フォント、画面の文言、機能の切り替え、独自のボタンとメニュー、ウォッチリスト、描画ツール、2 つの描画ツールバーに置くものは、チャートを表示したあとでも変えられます：

```ts
chart.applyOptions({ theme: 'dark', upColor: 'red' });
chart.applyOptions({ features: { replay: false } }); // 渡した切り替えだけを変える
chart.applyOptions({ accentColor: null }); // null でデフォルトに戻す
```

`features`、`messages`、`themes` はキーごとに元のものへマージし、ほかはまるごと置き換えます。`null` を渡すとデフォルトに戻ります。`timeZone` はデフォルト値で、まだ自分でタイムゾーンを選んでいないユーザーにだけ影響します。`datafeed`、`symbol`、`storage` のように作成時に 1 回だけ読むオプションは変えられず、渡すとエラーになります。テーマや言語の切り替えもこれで行います：`applyOptions({ theme: 'dark' })`、`applyOptions({ language: 'en' })`。
