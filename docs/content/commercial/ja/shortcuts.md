# キーボードショートカット

チャートにフォーカスがあるとき（たとえばチャートをクリックしたあと）は、次のキーを使えます。主要な相場ソフトの慣習と同じです。Mac では Alt は ⌥、Ctrl は ⌘、Shift は ⇧ で、画面にもそう書かれます。入力欄で文字を打っているときは働きません。ウィンドウ、ダイアログ、メニューの中では Alt か Ctrl を含むキーだけが有効です。`?` か Ctrl+/ でショートカットの一覧が開きます。トップバーのボタンや描画ツールバーのツールチップ、右クリックメニューにも対応するキーが書かれています。

| キー                                                           | 働き                                                                                                                                                                                                             | 必要な切り替え                                     |
| -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 英字をそのまま入力                                             | 銘柄検索を開き、入力した英字を入れておく                                                                                                                                                                         | `symbolSearch`                                     |
| 数字を入力（単位 `s`、`m`、`h`、`D`、`W`、`M` を続けてもよい） | 切り替える時間足を現在のチャートに表示します。`15` は 15 分、`4h`、`1D` など。Enter で切り替え、Esc で取り消し。時間足の一覧にはないがデータフィードが合成できる時間足は、ユーザーのカスタム時間足に追加されます |                                                    |
| `/`                                                            | インジケーターウィンドウ                                                                                                                                                                                         | `indicators`                                       |
| `?`、Ctrl+/                                                    | ショートカットの一覧                                                                                                                                                                                             |                                                    |
| ← →（Shift を押しながらで半画面ずつ）                          | 左右にスクロール                                                                                                                                                                                                 |                                                    |
| ↑、+ / ↓、−                                                    | 拡大 / 縮小                                                                                                                                                                                                      |                                                    |
| End                                                            | 最新の足へ移動                                                                                                                                                                                                   |                                                    |
| Alt+R                                                          | チャート表示をリセット                                                                                                                                                                                           |                                                    |
| Alt+I、Alt+L、Alt+P                                            | スケールを反転、対数スケール、パーセントスケール（もう一度押すと通常に戻る）                                                                                                                                     |                                                    |
| Alt+A                                                          | アラートウィンドウを開き、クロスヘアの価格を入れておく。ポインターがメインペインにないときは現在値                                                                                                               | `alerts`                                           |
| Alt+S                                                          | スクリーンショット（画像をダウンロード）                                                                                                                                                                         | `screenshot`                                       |
| Alt+Shift+S                                                    | 画像をクリップボードにコピー                                                                                                                                                                                     | `screenshot`                                       |
| Esc                                                            | 描いている途中の描画や、リプレイの開始点の選択を取り消す                                                                                                                                                         |                                                    |
| Alt+T、Alt+H、Alt+J、Alt+V、Alt+C、Alt+F、Alt+Shift+R          | トレンドライン、水平線、水平レイ、垂直線、十字線、フィボナッチ・リトレースメント、長方形（Alt+R は表示のリセットに使用済み）。もう一度押すと取り消し                                                             | `drawings`、かつツールが `drawingTools` にあること |
| Ctrl+Z / Ctrl+Y、Ctrl+Shift+Z                                  | 描画を元に戻す / やり直す                                                                                                                                                                                        | `drawings`、`history`                              |
| Delete、Backspace                                              | 選択した描画を削除                                                                                                                                                                                               | `drawings`                                         |
| Ctrl+C、Ctrl+V                                                 | 選択した描画をコピー、貼り付け                                                                                                                                                                                   | `drawings`                                         |

切り替えでオフにした機能のショートカットは働かず、一覧にも出ません。`features: { shortcuts: false }` は、矢印キーや Delete のようなチャート自身のキーも含めてすべてのショートカットをオフにし、チャート設定の「操作」にある「キーボードショートカット」の切り替えも一緒に隠します。ユーザーもこの切り替えで、チャートごとにショートカットをオフにできます。
