# 銘柄比較

トップバーの銘柄名の後ろにある ⊕ で比較ウィンドウが開きます。銘柄を検索し、行をクリックする（または Enter を押す）と「同じ％スケール」で追加します。ポインターを行に乗せると右側に 3 つのボタンが出て、次から選べます：

| 表示位置                     | メソッドの `placement` | 描き方                                                                                                                                                                                                 |
| ---------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 同じ％スケール（デフォルト） | `percent`              | メインペインの価格スケールに描き、スケールをパーセントに切り替えます。どの銘柄も視野内の最初の足の終値から数え、すべて 0% から始まってそれぞれの値動きで進み、ドラッグや拡大縮小のたびに計算し直します |
| 新しい価格スケール           | `scale`                | メインペインに、専用の価格スケールで描きます。1 つ目は左側の価格軸に置き、それ以降は軸を持ちません（値は凡例で見ます）                                                                                 |
| 新規ペイン                   | `pane`                 | 専用のペインに、専用の価格スケールで描きます                                                                                                                                                           |

ウィンドウの上部には現在のチャートで比較中の銘柄が並び、それぞれ外せます。追加してもウィンドウは閉じないので、続けて追加できます。メインペインが通常か対数のスケールのとき、「同じ％スケール」の銘柄を追加するとパーセントに切り替わります（100 基準のときは変わらず、同じく各銘柄が自分の最初の足から数えます）。あとで価格軸の右クリックメニューから通常に戻せます。

- 比較する銘柄はチャートの現在の時間足でデータを取得し（メインペインと同じく、データフィードの足の時間足から合成）、左へドラッグして古い足を読み込むときは一緒に読み込み、リアルタイムデータがあれば一緒に動きます（足のプッシュでも約定のプッシュでも構いません）。リプレイ中も同じく、リプレイした部分だけを表示します。
- 凡例の 1 行に名前と終値（その銘柄自身の小数桁）を表示し、価格軸にその最新値（パーセントのスケールではパーセント）を示します。現在値のラベルと重なるときは自動でずらします。ポインターをその行に乗せると、表示/非表示、設定、削除のボタンが出ます。設定ウィンドウでは表示位置、スタイル（チャートタイプと同じ名前・同じ描き方：バー、ローソク足、中空ローソク足、ライン、マーカー付きライン、ステップライン、エリア、HLCエリア、ベースライン、棒グラフ、ハイロー。メソッドの `style` は `ohlc`、`candles`、`hollow-candles`、`line`、`line-markers`、`step-line`、`area`、`hlc-area`、`baseline`、`columns`、`high-low`）、色と線の太さ（ラインとエリアの 5 種類。それ以外は上昇・下落の色）を変えられ、変更はすぐに反映されます。色を設定しないときは、パレットの末尾から順に、インジケーターがよく使う色を避けて取ります。
- メインペインの銘柄を替えても比較銘柄は残ります。チャートごとにそれぞれ比較銘柄を持ち、`ChartView.comparisons`（`{ id, symbol, placement, style, color, width, visible }`）に保存されます。

```ts
const id = await chart.addComparison('ETHUSDT'); // 同じ％スケール
await chart.addComparison('XAUUSDT', { placement: 'pane', style: 'area' });
await chart.updateComparison(id, { color: '#0d9488', width: 3 });
chart.on('comparisonsChange', ({ chart: index, comparisons }) => save(index, comparisons));
```
