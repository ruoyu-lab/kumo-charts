# 数式

中国の相場ソフトの書き方で書いたインジケーターの数式が、そのままプロチャートのインジケーターになります。足ごとにリアルタイムで計算し、インジケーターウィンドウに並び、ユーザーは組み込みのインジケーターと同じように追加したり、パラメーターやラインを変えたりでき、アラートも付けられます。数式は `customIndicators` に書き（またはあとから `registerIndicator()` で登録し）、アルゴリズムの `definition` の代わりに `formula` を使います：

```ts
import { createProChart, type CustomIndicator } from '@kumo-charts/pro-chart';

const MYMACD: CustomIndicator = {
  name: { en: 'My MACD', zh: '我的 MACD' }, // インジケーターウィンドウでコードの後ろに出る名前
  group: 'oscillators',
  formula: {
    type: 'MYMACD', // コード。インジケーターウィンドウと凡例に表示され、組み込みのインジケーターと同じ名前にはできない
    name: 'MYMACD', // 凡例の名前
    formula: `
      DIF:EMA(CLOSE,SHORT)-EMA(CLOSE,LONG);
      DEA:EMA(DIF,MID);
      MACD:(DIF-DEA)*2,COLORSTICK;
    `,
    params: { SHORT: 12, LONG: 26, MID: 9 }
  }
};

const chart = createProChart(container, {
  datafeed,
  symbol: '600519.SH',
  customIndicators: [MYMACD]
});
chart.addIndicator('MYMACD', { params: { SHORT: 6 } });
```

数式インジケーターのライセンスは商用ライセンスに含まれます。`name`、`group`、`origin` はほかの[カスタムインジケーター](custom-indicators.md)と同じです。

## オプション

| オプション  | 説明                                                                                                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `type`      | コード。`MYMACD` など。インジケーターウィンドウ、凡例、状態のどれでもこれを使い、組み込みのインジケーターやほかのカスタムインジケーターと同じ名前にはできません              |
| `name`      | 凡例に表示する名前                                                                                                                                                           |
| `formula`   | 数式のテキスト                                                                                                                                                               |
| `params`    | パラメーター。`{ N: 9 }` など。範囲も付けられます：`{ N: { default: 9, min: 1, max: 100, integer: true } }`。インジケーターの設定ウィンドウはこれに従って入力を制限します    |
| `overlay`   | `true` ならメインペインに描き、そうでなければ専用のサブペインに描きます                                                                                                      |
| `precision` | 小数桁。`price` は価格に合わせ（メインペインに描くときのデフォルト）、`volume` は出来高用                                                                                    |
| `levels`    | 水平の基準線。`[20, 80]` など                                                                                                                                                |
| `range`     | サブペインの固定のスケール範囲。`{ min: 0, max: 100 }` など                                                                                                                  |
| `timeZone`  | 時間関数が使うタイムゾーン。`Asia/Shanghai` など。デフォルトはチャートが時間を表示しているタイムゾーンで、ユーザーがタイムゾーンを替えると新しいタイムゾーンで計算し直します |
| `library`   | 参照できるほかの数式。下の「ほかの数式の参照」を参照                                                                                                                         |

## 書き間違えたとき

数式は `createProChart()` や `registerIndicator()` の時点でコンパイルされ、書き間違いがあるとすぐに `FormulaError`（`@kumo-charts/pro-chart` からインポート）を投げます。`code` はエラーの種類、`span` はエラーの位置、`describe('zh')` は中国語の説明です（`describe()` は英語の説明）：

```ts
import { FormulaError } from '@kumo-charts/pro-chart';

try {
  await chart.registerIndicator({ formula: { type: 'X', name: 'X', formula: 'A:MA(C,N);' } });
} catch (error) {
  if (error instanceof FormulaError) {
    error.span; // { line: 1, column: 8, length: 1 }
    error.describe('zh'); // "N"既不是前面定义过的变量、参数，也不是 CLOSE 这样的行情数据。
  }
}
```

## 構文

- `名前:式;` で 1 本のラインを描きます。`名前:=式;` は中間変数を定義するだけです。名前のない式もラインを描きます。
- 演算子：`+ - * /`、比較 `> < >= <= = <>`、論理 `AND OR NOT`（`&& || !` とも書けます）。優先順位は高い順に `* /`、`+ -`、比較、`NOT`、`AND`、`OR` です。そのため括弧のない `NOT C>O` は、中国の数式でよく書く `NOT(C>O)` と同じく「陽線でない」になります。`NOT` を比較の片側に置くときは括弧が必要で、`C>NOT(O)` のように書きます。
- 名前は大文字と小文字を区別せず、中国語も使えます。中国語の全角句読点（`；：，（）`）は自動的に認識し、引用符の中の文字はそのまま残します（`'买入，加仓'` の全角カンマは変わりません）。文字と参照は中国語の引用符 `‘’`、`“”` で囲むこともでき、半角の引用符で囲んだときは中に中国語の引用符を含められます。
- コメント：`{ … }` と `// …`。
- 相場データ：`OPEN/O`、`HIGH/H`、`LOW/L`、`CLOSE/C`、`VOL/V/VOLUME`。
- 線の属性：`COLORRED` などの色、`COLOR` に 6 桁の BBGGRR を続けたもの、`NODRAW`、`STICK`、`COLORSTICK`、`VOLSTICK`、`DOTLINE`、`DASHLINE`、`LINETHICK1`〜`9`（線の太さ。「描画関数」を参照）。

## 関数

| 分類           | 関数                                                                                                                                                                  |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 移動平均       | `MA` `EMA` `EXPMA` `SMA` `MEMA` `DMA` `WMA`                                                                                                                           |
| 参照           | `REF` `BARSLAST` `BARSSINCE` `BARSCOUNT` `BARSLASTCOUNT`                                                                                                              |
| 統計           | `SUM` `HHV` `LLV` `HHVBARS` `LLVBARS` `COUNT` `EVERY` `EXIST` `SUMBARS` `STD` `STDP` `VAR` `VARP` `AVEDEV` `DEVSQ` `SLOPE` `FORCAST`                                  |
| シグナル       | `CROSS` `LONGCROSS` `FILTER` `VALUEWHEN` `LAST` `NDAY` `UPNDAY` `DOWNNDAY`                                                                                            |
| インジケーター | `SAR`                                                                                                                                                                 |
| 時間           | `DATE` `TIME` `YEAR` `MONTH` `DAY` `HOUR` `MINUTE` `WEEKDAY` `BARPOS`                                                                                                 |
| 論理           | `IF` `IFF` `IFN` `NOT` `BETWEEN` `RANGE` `ISUP` `ISDOWN` `ISEQUAL`                                                                                                    |
| 数学           | `ABS` `MAX` `MIN` `SQRT` `POW` `LN` `LOG` `EXP` `INTPART` `FRACPART` `CEILING` `FLOOR` `ROUND` `ROUND2` `SIGN` `MOD` `REVERSE` `SIN` `COS` `TAN` `ASIN` `ACOS` `ATAN` |
| その他         | `DRAWNULL`                                                                                                                                                            |

いくつかの関数の詳細：

- `LAST(X,A,B)`：A 本前から B 本前まで（両端を含む）のすべての足で X が成り立つとき 1。A が 0 なら最初の足から、B が 0 なら現在の足までです。区間の始まりが最初の足より前のとき、または A が B より小さいときは 0。
- `NDAY(X,Y,N)`：直近 N 本のすべての足で X>Y。`UPNDAY(X,M)`、`DOWNNDAY(X,M)`：直近 M 本のすべての足が 1 本前より大きい（小さい）。等しいときは数えません。
- `RANGE(A,B,C)`：A が B より大きく C より小さいとき 1 で、両端は含みません。両端も含めるには `BETWEEN` を使います。
- `ROUND(X)` は整数に、`ROUND2(X,N)` は小数 N 桁に丸めます。どちらも四捨五入で、負の数の 0.5 も 0 から遠ざかる方向に丸めます（`ROUND(-2.5)` は -3）。書かれたとおりの 10 進数で丸めるので、`ROUND2(1.005,2)` は 1.01 です。N の小数部分は切り捨て、負の数は無効値になります。
- `FRACPART(X)` は小数部分で、符号が付きます：`FRACPART(-3.5)` は -0.5。
- `VALUEWHEN(COND,X)`：COND が最後に成り立った足の X。最初に成り立つまでは無効値。
- `SUMBARS(X,A)`：現在の足からさかのぼって X を A 以上になるまで足すのに何本必要か。現在の足だけで足りれば 1、すべて足しても足りなければその時点の足の本数です。X の無効値は 0 として扱います。
- `SAR(N,S,M)`：パラボリック SAR で、S はステップ、M は上限値で、どちらもパーセントです。`SAR(10,2,20)` のように書きます。最初の N 本の足には値がなく、起点を決めるのに使います。その次の足の終値が最初の足の終値より高ければ上昇から始め、SAR はこの N 本の最安値から始まります。そうでなければ下落から始め、最高値から始まります。その後は足ごとにトレンドの極値へ近づき、加速度は S% から始まって新しい極値を付けるたびに S% ずつ増え、最大 M% です。直前 2 本の足の範囲には入らず、価格が交差すると転換し、1 つ前のトレンドの極値から再び始めます。

### 期間

期間の引数（`MA(C,N)` の `N` など）は、数値、パラメーター、それらの四則演算でも、系列でも構いません。`HHV(H,BARSLAST(CROSS(C,MA(C,5)))+1)` は前回 5 日移動平均を上抜けて以降の最高値、`SUM(V,BARSLAST(CROSS(C,MA(C,5)))+1)` はその期間の出来高です。`LONGCROSS`、`FILTER`、`SAR` を除き、期間はどれも系列にできます。

- 数値やパラメーターで書くとき、期間は整数で、その関数の下限（次の項目を参照）以上でなければならず、そうでないとコンパイル時に `invalid-period` が報告され、下限がいくつかが示されます。`REF` の期間を負の数で書くとそれ以降の足（未来のデータ）を参照することになり、`future-reference` が報告されます。
- 系列を期間にすると、各足はその足の期間の値を使い、小数部分は切り捨てます（2.7 は 2）。期間が無効値か負の数なら、結果は無効値です。
- 0 の意味は数値で書いたときと同じです。`SUM`、`HHV`、`LLV`、`HHVBARS`、`LLVBARS`、`COUNT`、および `LAST` の A に 0 を書くと最初の足から数え、`REF` の 0 は現在の足です。ほかの関数の期間は最低 1（`STD`、`VAR`、`SLOPE`、`FORCAST` は最低 2）で、それより小さいと無効値です。
- 足の本数が期間に満たないときも数値で書いたときと同じです。`COUNT`、`EXIST` はある分だけを数え、`EVERY`、`NDAY`、`UPNDAY`、`DOWNNDAY`、`LAST` は 0、ほかは無効値です。
- `EMA`、`SMA` のような再帰的な移動平均は、足ごとにその足の期間で計算し、期間が無効な足は結果が無効値になり、再帰にも加わりません。

## 描画関数

ローソク足の上にシグナルを描きます。書き方は中国の相場ソフトの数式と同じで、それぞれ独立した 1 文にし、後ろに色を続けられます：

```text
金叉:=CROSS(MA(C,5),MA(C,10));
DRAWICON(金叉,LOW,1);
DRAWTEXT(金叉,HIGH+MA(HIGH-LOW,20),'金叉'),COLORRED;
STICKLINE(VOL>MA(VOL,20)*2,OPEN,CLOSE,0.8,0),COLORYELLOW;
DRAWBAND(MA(C,5),COLORRED,MA(C,20),COLORGREEN);
DRAWLINE(H>=HHV(H,20),H,L<=LLV(L,20),L,1),COLORMAGENTA,LINETHICK2;
```

| 関数                                     | 描き方                                                                                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `STICKLINE(条件,価格1,価格2,幅,中空)`    | 条件が成り立つ足に、価格 1 から価格 2 まで柱を描きます。幅 0 は細い線、0.8 はローソク足の実体と同じ幅、1.1 以上は間隔いっぱいです。中空が 0 でなければ枠線だけを描きます                                                                                                                                                                                                      |
| `DRAWTEXT(条件,価格,'文字')`             | 価格の位置に文字を書きます（価格を中心に）                                                                                                                                                                                                                                                                                                                                    |
| `DRAWNUMBER(条件,価格,数値)`             | 価格の位置に数値を書きます（価格を中心に）。数値は系列でも構いません。整数は小数なしで、ほかの数は数式の小数桁で、凡例と同じように書きます                                                                                                                                                                                                                                    |
| `DRAWICON(条件,価格,アイコン)`           | アイコン 1 は上向きの矢印で、先端が下から価格を指します。2 は下向きの矢印で、上から価格を指します。ほかの番号はドットを描きます                                                                                                                                                                                                                                               |
| `POLYLINE(条件,価格)`                    | 条件が成り立つ点を順に折れ線でつなぎ、あいだの足は飛ばします。`PLOYLINE` とも書けます                                                                                                                                                                                                                                                                                         |
| `VERTLINE(条件)`                         | 条件が成り立つ足に、ペインの上端から下端まで縦線を引きます                                                                                                                                                                                                                                                                                                                    |
| `DRAWLINE(条件1,価格1,条件2,価格2,延長)` | 条件 1 が成り立つと始点を記録し（また成り立つと新しい始点に替わる）、その後に条件 2 が成り立つと始点からそこまで直線を引きます。始点はそこで使い切り、次の線は条件 1 が再び成り立つのを待ちます。2 つの条件が同じ足で成り立つと、まずそこで前の線を終え、それからそこで新しい線を始めます。延長：0 は延長なし、1 はペインの右端まで延長、2 か 10 は左へ、3 か 11 は両側へ延長 |
| `DRAWBAND(値1,色1,値2,色2)`              | 値 1 が値 2 より高いところは色 1 で、逆は色 2 で、2 つの値のあいだを塗りつぶします。色は `COLORRED` のような色名か、`COLOR` に 6 桁の BBGGRR を続けたもので書きます。塗りつぶしは半透明で、ローソク足を隠しません                                                                                                                                                             |
| `DRAWKLINE(高値,始値,安値,終値)`         | この 4 つの値でローソク足を描きます。終値が始値を下回らないものが陽線で、上昇・下落の色はチャートのテーマに従います                                                                                                                                                                                                                                                           |
| `PARTLINE(価格,条件1,色1,条件2,色2,…)`   | 価格のラインを描き、各足は最初に成り立つ条件の色を使い、どれも成り立たないところは描きません。色が切り替わるところで 2 つの区間はつながるので、色の変わる 1 本のラインになります。条件と色は 1 組でも複数組でも渡せます                                                                                                                                                       |
| `FILLRGN(価格1,価格2,条件1,色1,…)`       | 2 つの価格のあいだを塗りつぶし、各足は最初に成り立つ条件の色を使い、どれも成り立たないところは塗りません。塗りつぶしは半透明で、`DRAWBAND` と同じ濃さです                                                                                                                                                                                                                     |
| `DRAWGBK(条件,色)`                       | 条件が成り立つ足の後ろで、ペイン全体の背景をその色でうっすら染め、続く足は 1 つのまとまりになります。ローソク足の下にあり、ローソク足を隠しません                                                                                                                                                                                                                             |

- 描画関数の引数は、条件が成り立たないときも含めて足ごとに計算するので、`MA`、`REF` のような関数を引数に入れても結果は変わりません。
- 幅、中空、アイコン番号、延長は数値かパラメーターである必要があり、文字は引用符で囲みます。
- 色を書かないとき、矢印はチャートのテーマの買いと売りの色を、`DRAWKLINE` はテーマの上昇・下落の色を、ほかの図形はテーマのラインの色を順に使います。中国の相場ソフトではアイコン 1 番と 2 番は赤と緑に固定ですが、ここではテーマに従い、緑が上昇のチャートで買いを赤く描かないようにしています。
- `LINETHICK1`〜`9` は線の太さを設定します。普通のラインも `POLYLINE`、`DRAWLINE`、`VERTLINE` も同じで、1 がデフォルトの太さ、2〜9 は 2〜9 ピクセルです。`DOTLINE`、`DASHLINE` はそれらを点線、破線にします。ユーザーがインジケーターの設定で変えた線の太さが優先されます。
- `DRAWLINE` は前もって線を引きません。線は条件 2 が成り立つ足が現れたときに引かれ、引いたあとは変わりません。
- 描画は凡例に表示されません。スケールは柱の両端、マーク、数値、折れ線の各点、直線の両端、帯状の領域のための余白を取り、縦線は余白を取りません。描画だけのサブペインも正しく表示されます。
- 描画関数は独立した 1 文にする必要があり、式の中に入れたり名前に代入したりできません。

## ほかの数式の参照

`"数式名.ライン名"` で、ほかの数式のラインを 1 本読みます。その数式のデフォルトのパラメーターを使います：

```text
XG:CROSS("MACD.DIF","MACD.DEA") AND "KDJ.J"<20;
```

後ろに括弧を付けると独自のパラメーターを渡せます。その数式のパラメーターの順に、それぞれ数値かこの数式のパラメーターで、渡さなかったものはデフォルト値を使います：

```text
快:"MACD.DIF"(5,20); 慢:"MACD.DIF"; 金叉:CROSS("MACD.DIF"(N,20,9),"MACD.DEA"(N,20,9));
```

- 既製の数式はどれも名前で参照できます：`MA`、`BOLL`、`MACD`、`KDJ`、`RSI`、`CCI`、`WR`、`BIAS`、`TRIX`、`OBV`。
- 自分の数式も `library` オプションに入れれば参照でき、同じ名前のときは既製のものより優先されます：`{ library: { 我的均线: { formula: 'FAST:MA(C,N);', params: { N: 5 } } } }`。
- 名前は大文字と小文字を区別しません。中国語の引用符 `“”` も使えます。
- 同じ数式を同じパラメーターで何度参照しても計算は 1 回だけです。互いに参照して循環する場合や、存在しない数式やラインを参照する場合はエラーになり、その位置を示します。数式はそのコード（`type`）で自分を識別します。同じ名前の数式を参照すると自分自身の参照になります。凡例に表示する `name` は数えないので、`name: 'MACD'` の数式でも既製の `"MACD.DIF"` を参照できます。
- 参照された数式そのものに誤りがあると `broken-reference` が報告され、位置は参照している場所を指し、説明にはその数式の何行目何列目のどこが誤っているかが含まれます。`error.referenced` はその数式の元の `FormulaError` です。

## 中国の相場ソフトとの違い

- **無効値**：データが足りないとき（`MA(C,5)` の最初の 4 本など）、0 で割ったとき、無効値と比較したときは、どれも結果が無効値になり、チャートには描きません。移動平均系の関数は無効値を飛ばします。
- **足が期間に満たないときの `HHV`、`LLV`、`SUM`**：足の本数がまだ期間に満たないとき、ここでは無効値になり（`HHV(H,20)` の最初の 19 本は描かない）、チャートライブラリの組み込みインジケーターと同じです。中国の相場ソフトは普通、ある分の足で値を計算するので、最初の区間は両者で異なり、その後はまったく同じです。最初の足から値が欲しいときは、`IF(BARSCOUNT(C)>=20,HHV(H,20),HHV(H,0))` と書けます（期間 0 は最初の足から数える）。
- **未対応**：そのほかの描画関数（`DRAWBMP`、`DRAWSL`、`DRAWTEXT_FIX` など）、売買関数（`BUY`、`SELL`）、`AMOUNT`（足に売買代金がないので結果は無効値）、時間足をまたぐ参照（`"MACD.DIF#WEEK"` など）。
- **時間**：`DATE` は中国の相場ソフトと同じく 1900 年から数え（2026-10-21 は `1261021`）、`TIME` は `HHMMSS`（9:30 は `93000`）、`WEEKDAY` の 0 は日曜日です。時間は足の**開始時刻**を取りますが、中国の相場ソフトの分足は終了時刻を使います。同じ 9:30〜9:35 の足で、ここでは `TIME` が `93000`、向こうでは `93500` です。
- **未来関数**：`ZIG`、`PEAK`、`PEAKBARS`、`TROUGH`、`TROUGHBARS`、`BACKSET`、`REFX`、`REFXV`、`CONST`、`XMA`、`CURRBARSCOUNT`、`TOTALBARSCOUNT`、`ISLASTBAR`、`BARSTATUS`、`BARSNEXT`、`FILTERX` はそれ以降の足を使います。描いたラインやシグナルが新しい足とともに書き換わり（リペイント）、振り返ると見栄えはよくてもリアルタイムでは得られないので、対応していません。書くと `future-function` エラーになり、位置を示し、別の書き方があればあわせて案内します。たとえば `ZIG` が探す高値・安値は、`HHV`、`LLV` と `BARSLAST` で確定済みのものを求められ、`XMA` は `MA` に替えられます。
- **SAR の起点**：`SAR` の始め方はソフトによって異なり、ここでの起点は上で説明したとおりです。そのため最初の区間の値や転換点はほかのソフトと異なることがあり、何度か転換すると同じになります。起点の区間を過ぎれば（普通は最初の数十本のうちに何度か転換したあと）、チャートライブラリの組み込みの SAR と足ごとに一致します（パラメーターを小数にして：`SAR(10,2,20)` は 0.02、0.02、0.2 に対応）。`N` が 1 なら最初から最後まで一致します。
