# インジケーター

インジケーターウィンドウはチャートを覆わない小さなウィンドウで、左の列か上部の空いたところをつかんでどこへでもドラッグでき、閉じてまた開いても同じ位置にあります。左の列は区切り線で 3 つに分かれます：すべて。お気に入り、インジケーターテンプレート。トレンド、バンド、オシレーター、出来高、ボラティリティ、オーダーフロー（ページ独自のインジケーターにグループがないときは「その他」も加わります）。右側の上部には選んだ分類の見出しと閉じるボタン、その下に検索欄があります（インジケーターテンプレートのページではテンプレート名と保存ボタン）。ウィンドウには、チャートライブラリのインジケーターモジュールにある 87 種類すべて（どのチャートにも登録済み）、オープンソースのチャートライブラリの 2 種類の価格帯別出来高（`@kumo-charts/core/volume-profile`：VPVR は表示範囲、VPSV は日ごと）、そして商用版のオーダーフローの 3 つのインジケーター（データフィードに `getTradeMinutes()` があるとき）、大口約定と板情報ヒートマップ（データフィードに `subscribeBook()` があるとき）が並びます：

どのインジケーターも、インジケーターウィンドウでコードかいずれかの言語の名前で検索でき、設定ウィンドウでパラメーター、ライン、基準線を変えられます：

- 1 つの価格から計算するインジケーター（移動平均系。DEMA、TEMA、LSMA、MCGINLEY、RIBBON を含む。BBI、ALLIGATOR、BOLL、KC、ENVELOPE、VSTOP、MACD、RSI、STOCHRSI、WR、CCI、ROC、BIAS、DMA、TRIX、MTM、DPO、PSY、FISHER、AO、PPO、CMO、KST、COPPOCK、TSI、CRSI、STD、BBW、BBP、VWAP）は価格を選べます：終値、始値、高値、安値、(H+L)/2、(H+L+C)/3、(O+H+L+C)/4。FISHER、AO、ALLIGATOR のデフォルトは (H+L)/2、VWAP のデフォルトは (H+L+C)/3 です。
- 選択式のパラメーターはドロップダウンかセグメントボタンです：PIVOTS の種類（標準、フィボナッチ、ウッディ、クラシック、デマーク、カマリラ）と、PIVOTS、PREVHLC、ADR の期間（日、週、月、四半期、年。銘柄の取引カレンダーに従う）。メソッドでは選択肢の番号を使います：`addIndicator('PIVOTS', { params: { kind: 1, period: 1 } })` は週単位のフィボナッチ・ピボットポイントです。
- RIBBON（移動平均リボン）は 4 本の移動平均で、それぞれに種類（SMA、EMA、SMMA (RMA)、WMA、VWMA）と期間があり、デフォルトは 20、50、100、200 の SMA です。不要なものはスタイルのタブでオフにします。
- PIVOTHL（ピボット高値・安値）は高値と安値それぞれに左右の足の本数（デフォルトはどれも 10）があり、各ピボットにはその足に三角を描いて価格を書きます。
- ZIGZAG（ジグザグ）は価格の転換点を結びます。パラメーターは転換点の乖離（%、デフォルト 5）、深さ（デフォルト 10。左右それぞれ半分の足で確定）、最新の足まで延長、そしてラベルに何を書くか――転換点の価格、転換点の変化（絶対値またはパーセント）、累積出来高（1 つ前の転換点の後からこの転換点まで）で、どれもデフォルトでオンです。最後の転換点は相場の動きにつれて、同じ方向のより遠い転換点に置き換わり、ラインとラベルもそれに合わせて動きます。高値のラベルは上側にテーマの上昇の色で、安値のラベルは下側に下落の色で、どれも描画領域の中に描き、価格軸には重なりません。スタイルのタブには「ジグザグ」のライン 1 本だけがあり、色、太さ、線種を変えられ、オフにするとラインもラベルも描きません。別の時間足で計算するときは、転換点をその時間足の足が確定する位置に描き、出来高はその時間足の足の出来高を合計したものです。
- 水平の線分（ピボットポイント、前期間の高値・安値・終値、ADR）は、ラインと同じく色、太さ、線種を変えられます。取引セッションの枠（東京、ロンドン、ニューヨークの株式市場の取引時間。それぞれのタイムゾーンと夏時間に従う）は、それぞれ色を変えたり個別に隠したりでき、設定には各セッションの時間が書かれています。
- ラインの名前は画面の言語で表示されます。凡例、スタイルのタブ、アラートウィンドウ、アラートの文言では、ボリンジャーバンドは中心線・上限バンド・下限バンド、MACD はヒストグラム・MACD・シグナルです。MA9、%K、R1 のようなコードはどの言語でも同じで、ページ独自のインジケーターは自分で付けた名前を使います。チャートの `chart.indicators.valuesAt()` の `label` も画面の言語の名前です。
- メインペインのインジケーターには、スタイルのタブに「自動スケールに含める」があります。オフにするとそのラインは価格軸の自動スケールに加わらず、価格から遠いときはチャートの外に描かれ、ローソク足を押しつぶしません。ピボットポイント、前期間の高値・安値・終値、取引セッションの枠はデフォルトでオフ（R5、S5 などは価格から遠いため）、ほかはデフォルトでオンです。メソッドでは `autoscale` で、`true`、`false`、またはインジケーターのデフォルトに従う `null` です。
- 価格帯別出来高（VPVR、VPSV）のパラメーターには「内訳」があります：**陽線・陰線**（デフォルト。オープンソースのチャートライブラリの描き方で、各行を足が陽線で終わったか陰線で終わったかで 2 色に分ける）か、**成行買い・売り**（商用版のオーダーフローの描き方）です。成行買い・売りを選ぶと、各行の出来高は約定（1 分ごと・価格ごとの成行買いと成行売りの出来高）から取ります。前半（伸びていく側の辺に接する部分）が成行買い、後半が成行売りで、全体の長さは変わらず合計の出来高です。POC とバリューエリアはオープンソース版と同じく合計から計算します。価格帯の数、バリューエリア、幅、位置はこれまで通り効き、リプレイ中は再生済みの部分だけを計算します。スタイルのタブの 2 つの色は成行買い出来高と成行売り出来高になり（デフォルトはテーマの買いと売りの色）、切り替えると元の 2 つの色は位置どおりに引き継がれます。成行買い・売りを選べるのは、データフィードに `getTradeMinutes()` があるときだけです。ないときはこの選択肢がグレーになり、その下に理由が書かれます。
  - 約定は出来高フットプリントと共有し（同じ銘柄の複数のチャートでも共有）、新しいものから順にさかのぼって取得します。1 つのプロファイル（取引日ごとなら 1 日）の約定がそろっていないときはそれを描かず、その位置に「読み込み中」「約定なし」「失敗」（しばらくして自動で再試行）と書き、チャートの左下に理由を一言書きます。チャートを開いた直後は、現在の 1 分の約定はその 1 分が終わってから履歴で埋まるので、最新の足を含むプロファイルが出るまで最大で 1 分あまりかかります。データフィードが直近の一定期間の約定しか返さないときは、範囲にそれより古い足があると描けないので、最近の足まで縮めるよう促します。
  - 計算するのは最大 3 日分の約定です。表示範囲がそれを超えると描かず、「範囲が広すぎます」と書きます。取引日ごとのときは直近 3 日だけを描き、それより前の日にはそう表示します。秒足は成行買い・売りで分けられません（約定は分ごとに保存するため）。
  - メソッドでは `params: { split: 1 }`（`0` が陽線・陰線）で、ラインは `buy`、`sell`、`poc` です。状態では各チャートの `indicators` の `params` に保存されます。商用ライセンスキーに含まれます。
- **オーダーフロー**のグループは、商用版のオーダーフローが約定ごとのアグレッサー側から計算する 3 つのインジケーターで、それぞれ専用のサブペインに入ります。ほかのインジケーターと同じく凡例の値とボタン、設定ウィンドウがあり、別のペインへ移せて、レイアウトとインジケーターテンプレートに保存されます：
  - **VD 出来高デルタ**（Volume Delta / 成交量差 / 거래량 델타）：足ごとに 1 本のローソク足で、0 からその足の成行買い出来高 − 成行売り出来高までを表し、高値と安値は 1 分ごとに足していった差が到達した最高と最低です。0 に基準線が 1 本あります。凡例には O、H、L、C の 4 つの値を書きます。
  - **CVD 累積出来高デルタ**（Cumulative Volume Delta）：各期間の始まりから出来高デルタを積み上げ、各ローソク足はその足が始まったときの累積から終わったときの累積までで、高値と安値は 1 分ごとです。期間ごとに 0 から計算し直します。期間はパラメーター**リセット周期**（`anchor`。VWAP の同名パラメーターと同じ選択肢と名前）で、**毎日**（`0`、デフォルト。銘柄の取引カレンダーの取引日）、**毎週**（`1`）、**毎月**（`2`）があり、銘柄の取引カレンダーで区切ります。凡例では名前の後ろにこれを書きます（`CVD 毎週`）。四半期と年はありません：30 日を超える約定になるためです。足は始まった期間に数え、足が期間と同じかそれより長いとき（日足で毎日を選んだとき）は、各足が 0 から始まります。
  - **UDV 売買別出来高**（Up/Down Volume）：成行買い出来高を 0 の上に、成行売り出来高を 0 の下に描き（テーマの上昇と下落の色）、差を「—」で描きます。
  - ローソク足は棒グラフと同じく上昇・下落で色分けし、スタイルのタブには「陽線・陰線の色に合わせる」とあります。色を設定するとすべてその色になります。パラメーターはありません。
  - 約定は出来高フットプリント、成行買い・売りで分けた価格帯別出来高と共有し、画面上の足だけを、新しいものから取得します。必要なのは 1 分ごとの売買の出来高だけで、約定は最大 30 日分です（日足なら最大 30 本。CVD はその期間の始まりから取得し、始まりが 30 日より前になる期間は描かずに「範囲が広すぎます」と書きます。たとえば 31 日ある月の最終日）。足は各分の約定がすべてそろったときだけ描きます。CVD はその期間の始まりからその足の終わりまでのすべての分がそろっている必要があり、1 分でも欠けると、その期間のそれ以降はすべて描きません。**途中から数えた累積は決して描きません**。描かなかった足には、サブペインに「読み込み中」「約定なし」「失敗」「範囲が広すぎます」と書き、チャートの左下に理由を一言書きます。秒足や、練行足・カギ足のような時間によらない足には描かず、そのことも明記します。チャートを開いた直後は、現在の 1 分が終わって履歴で埋まってから最新の足が描かれます。
  - リアルタイムの約定が来ると、最新の 1 分だけを読み直し、最新の 1 本だけを計算し直します。リプレイ中は再生済みの足だけを計算します。
  - これらが読む約定はチャート上にしかなく、バックグラウンドで監視するアラートにはないので、これらにはアラートを付けられません（凡例にベルがなく、アラートウィンドウにも出ません）。
  - メソッドでは `addIndicator('CVD')` です。データフィードに `getTradeMinutes()` がないときはウィンドウに出ず、`addIndicator` はエラーを投げます。商用ライセンスキーに含まれます。

- **大口約定**（LARGETRADES）と**板情報ヒートマップ**（BOOKHEATMAP）は「オーダーフロー」グループにあり、商用版のオーダーフローが描きます。価格帯別出来高と同じくメインペインに描き、専用のペインはなく、アラートも付けられません。1 つのチャートでは同じ種類のうち最初に表示しているものだけを描きます。凡例にはこれらの行がなく、「チャート要素」パネルに並び、そこから設定を開きます。
  - **大口約定**：メインペインのローソク足の上に浮かぶバブルで、約定の時間（その足の幅の中に置き、足の始まりが左）と価格の位置にあり、面積は約定代金（価格 × 数量）、色はアグレッサー側（デフォルトはテーマの買いと売りの色）で決まります。パラメーター：**基準**（`threshold`）は**自動**（`0`。画面上の足の中で約定代金が大きい順に「件数」件）か**最低約定代金**（`1`。約定代金が「最低約定代金」以上のすべての約定。決済通貨建て）、**件数**（`count`、デフォルト 50、1〜500）、**最低約定代金**（`minValue`、デフォルト 100000）、**サイズ**（`size`、最大のバブルの半径のピクセル数、デフォルト 18、4〜60）。ラインは `buy` と `sell` です。「チャート要素」には件数（自動）か `≥ 最低約定代金` が書かれます。約定は出来高フットプリントと共有し（同じ銘柄の複数のチャートでも共有）、データフィードに `getTradeMinutes()` があればチャートを開く前の分も埋め（1 分ごとに約定代金の大きい 32 件）、なければ開いた後の分だけです。足の大口約定はその足の約定がそろってから描き、約定は最大で直近 3 日分です。秒足には描かず（約定は分ごとに保存するため）、リプレイ中は再生済みの分だけを描きます。描けない理由はチャートの左下に書きます。約定を分ごとに保存するとき、各分には約定代金の大きい 32 件だけが残ります。1 分の中に設定した下限より大きい約定が 32 件を超えてあると、実際に描く下限はその分に残った最小の 1 件より上に引き上げられ、描く下限より大きい約定は 1 件も漏らさないようにします（`chart.largeTrades.status().threshold` が実際にどこまで小さく描くかです）。
  - **板情報ヒートマップ**：メインペインのローソク足の後ろに描き、ピクセルの各列はその時間帯の平均の注文数量、ピクセルの各行はその価格のうち注文が最も多い行です。買い板はテーマの買いの色、売り板は売りの色で、多いほど不透明になります（画面上のマスの 99 パーセンタイルで最大）。右端には現在の板を描きます（いちばん長い行が描画領域の幅の 12%）。パラメーター：**不透明度**（`opacity`、最大のときの不透明度、パーセント、デフォルト 80）、**現在の板**（`profile`、`1` で表示、`0` で非表示）。ラインは `buy`（買い板）と `sell`（売り板）です。ヒートマップは板情報を購読してからの分しかなく（取引所は過去の板情報を提供しません）、途切れた数秒は空になります。まだ板情報がないときはチャートの左下に今から記録する旨が、途切れたときは板情報が途切れている旨が書かれます。
  - メソッドでは `addIndicator('LARGETRADES', { params: { threshold: 1, minValue: 250000 } })`、`addIndicator('BOOKHEATMAP', { params: { opacity: 60 } })` です。ペインを指定するとエラーになります。商用ライセンスキーに含まれます。

**インジケーターテンプレート**はインジケーターウィンドウの左側の「インジケーターテンプレート」にあります。名前を入れて保存すると、現在のチャートのインジケーターが、パラメーター、ライン、基準線の設定ごと 1 つのテンプレートとして保存されます（同じ名前があるときは確認してから置き換えます）。テンプレートをクリックすると、現在のチャートのインジケーターがテンプレートのものに置き換わります（元のインジケーターは外れ、比較銘柄と描画はそのまま）。ゴミ箱でテンプレートを削除します。テンプレートは名前順に並び、検索欄でも名前で探せます。テンプレートは状態の `indicatorTemplates` に保存され（`[{ name, indicators }]`。`indicators` は各チャートの `indicators` と同じ形式）、すべてのチャートで共通で、`storage` や `getState()` と一緒に扱われます。
