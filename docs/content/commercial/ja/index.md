# Kumo Charts 商用版

Kumo Charts 商用版は、オープンソースの [Kumo Charts](../../ja/index.md) の上に作られた商用コンポーネントで、[商用ライセンス](license.md)を購入して使います。中心になるのは**プロチャート**です。一通りのツールがそろった相場監視用のチャートで、自前の相場データにつなげばそのまま Web ページに埋め込めます。Vue、React、普通の Web ページのどれでも使えます。

```ts
import { createProChart } from '@kumo-charts/pro-chart';

const chart = createProChart(document.getElementById('chart')!, {
  datafeed: myDatafeed,
  symbol: '600519.SH'
});
```

[クイックスタート](getting-started.md)から読み始めてください。

## 含まれるもの

- **プロチャート**（`@kumo-charts/pro-chart`）：トップバーの銘柄検索、銘柄比較、時間足、チャートタイプ、インジケーターとインジケーターテンプレート、リプレイ、元に戻す・やり直す、スクリーンショットとチャートデータのエクスポート、左側の描画ツール、マルチチャートレイアウト、右クリックメニュー、チャート設定とインジケーター設定のウィンドウ、そして価格・インジケーター・描画の[アラート](alerts.md)。トップバーはまるごと外してページ独自のものに置き換えられ、ページのウォッチリストは銘柄検索の星印につなげられます。ボタン、右クリックメニュー、インジケーター、描画ツールにはページ独自のものを追加できます。
- **オーダーフロー**：出来高フットプリントとタイム・プライス・オポチュニティ（TPO）の 2 つの[チャートタイプ](chart-types.md)、出来高デルタ・累積出来高デルタ・売買別出来高の 3 つの[インジケーター](indicators.md)、大口約定と板情報ヒートマップ、そして成行買い・売りで分けた価格帯別出来高。
- **情報駆動型の足**：インバランスバーとランバー。リアルタイムの約定から作ります。
- **数式インジケーター**：中国の相場ソフトの書き方で書いた[数式](formula.md)が、そのまま約定ごとにリアルタイムで計算するインジケーターになります。

これらはすべてプロチャートに入っていて、1 つの商用ライセンスキーですべてが使えます。

## 買う前に試す

自分のパソコンの開発サーバー上のページ（`localhost`、`127.0.0.1` など）ではライセンスキーが要らず、ウォーターマークも出ないので、すべての機能を試せます。本番の Web サイトやアプリに置くと、ライセンスキーのないチャートは左下に「Kumo Charts 商用版 · ライセンス未登録、評価専用」と表示します。ライセンスには個人と法人の 2 種類があり、[kumocharts.com](https://kumocharts.com/ja/#pricing) で購入できます。支払いが済むとすぐにライセンスキーが届きます。ルールは[ライセンス](license.md)を参照してください。

## 画面の概要

チャート上で右クリック：チャート表示をリセット（Alt+R、Mac では ⌥R）、価格をコピー、この価格にアラートを追加（クリック 1 回で追加）、アラートを追加…（Alt+A、アラートウィンドウを開く）、この足からリプレイ、インジケーターを追加、描画の非表示・削除、アラートの削除、スクリーンショット、チャート設定。描画やアラートラインの上で右クリックすると、それぞれの操作が出ます（描画：そのラインにアラートを追加…、コピー、ロック、非表示、削除。アラートライン：アラートを編集…、一時停止、削除。アラートラインをダブルクリックしても編集が開きます）。価格軸で右クリック：この価格にアラートを追加…、価格軸をリセット、自動スケール、スケールを反転（Alt+I）、通常、パーセント（Alt+P）、100 基準、対数（Alt+L）、そして現在値のラベル、ライン、足確定までのカウントダウン。これらはチャートごとに保存されます。サブペインの価格軸にはリセットと自動スケールだけがあります。時間軸で右クリックすると時間軸をリセットできます。

マルチチャートレイアウトはトップバーの右側にあります：1 枚、左右に 2 枚、上下に 2 枚、3 枚の 2 通りの並べ方（左に大 1 枚・右に小 2 枚、左に小 2 枚・右に大 1 枚）、4 枚、そして 6 枚の 4 通りの並べ方（2 行 3 列、3 行 2 列、左に大 1 枚・右に小 5 枚、上に大 1 枚・下に小 5 枚）。ほかのチャートを、現在のチャートに合わせて銘柄の切り替え、時間足の切り替え、クロスヘアの移動、時間の同期に追従させられます（時間足はデフォルトでは追従せず、チャートごとに別の時間足を見られます）。チャートの境目はどれもドラッグしてサイズを変えられます。チャートは最低でも 200×120 ピクセルを確保し、場所が足りないときは均等に分けます。境目をダブルクリックすると、その方向の境目がデフォルトの位置に戻ります。

時間軸の右下（価格軸の下）には、チャートの時間のタイムゾーンが `UTC+8` のように表示されます。クリックすると、取引所の時間（銘柄の取引カレンダーのタイムゾーン。データフィードがカレンダーを返さない銘柄は、各プラットフォームの暗号資産のように UTC の 24 時間取引として扱います）、UTC、ローカル時間、主要都市のタイムゾーンから選べます。どの項目にも現在の UTC オフセットが付きます。選んだものは状態に保存され、すべてのチャートで共通です。変わるのは表示する時間だけで、足は今まで通り銘柄の取引カレンダーで区切ります。リプレイの小ウィンドウの時間もこのタイムゾーンに従います。

描画を選択すると、その横によく使うツールのツールバー（色、線の太さ、線種、コピー、ロック、削除）が浮かびます。ツールバーの歯車をクリックするか描画をダブルクリックすると、描画の設定ウィンドウが開きます。タブは 4 つです：スタイル（線、塗りつぶし、左右への延長、矢印、フィボナッチの各レベルの値・色・表示）、テキスト（内容、色、サイズ、太字・斜体、揃えと位置）、座標（各ポイントの時間と価格。正確に入力できます）、表示する時間足（秒・分・時間・日・週・月のどの時間足で表示するか）。変更は入力やドラッグと同時に反映され、元に戻すときは 1 回の編集が 1 ステップです。1 つの入力欄に続けて打った文字や、不透明度スライダーの 1 回のドラッグは、1 回の「元に戻す」でまとめて戻ります。ツールごとにユーザーが最後に設定したスタイルを覚えていて、新しく描く描画はそのスタイルを使います。テキスト描画はダブルクリックすると、これまで通りチャート上で直接編集します。

リプレイの操作はチャート上に浮かぶ小ウィンドウで行います。左端のドットをつかんで好きな位置にドラッグでき、位置は保存されます。ダブルクリックすると元の位置に戻ります。リプレイの開始点を選ぶあいだは、ポインターのある足より右側の、リプレイで隠れる部分が薄く表示されます。

マルチチャートレイアウトでは、同じ銘柄のチャートが一緒にリプレイします。リプレイをクリックすると、その銘柄を表示しているどのチャートでも開始点を選べて、マウスのあるチャートに隠れる部分が表示されます。クリックしたチャートから始まり、そのチャートが現在のチャートになります。リプレイの操作はそのチャートの時間足で進み、同じ銘柄のほかのチャートは同じ時間に追従します。それより大きな時間足のチャートは、代わりにそのチャートと同じ細かさの足から合成するので、進行中の足は少しずつ伸びていき、それ以降の価格は見えません。データの切り替えには少し時間がかかり、そのあいだそのチャートは空になります。ほかの銘柄のチャートは通常通りリアルタイムの相場を表示します。同じ銘柄のどのチャートでリプレイを終了しても、すべてがリアルタイムに戻ります。

## スクリーンショットとデータのエクスポート

トップバー右側のカメラボタンはメニューになっています：

- **画像をダウンロード**（Alt+S）：現在のチャートを PNG で保存します。ファイル名は `BTCUSDT-1h.png` のようになります。
- **画像をコピー**（Alt+Shift+S、Mac では ⌥⇧S。Ctrl+Shift+S はブラウザによってはブラウザ自身のスクリーンショットです）：現在のチャートの画像をクリップボードに入れ、チャットやドキュメントにそのまま貼り付けられます。ブラウザがページにクリップボードへの画像の書き込みを許さないとき（古いブラウザや、https でないページ）は、代わりにその画像をダウンロードし、一言お知らせします。

データのエクスポートはデフォルトでは表示されません。`features: { dataExport: true }` で有効にすると、レイアウトのメニュー（トップバー右側のマルチチャートレイアウトのボタン、その最後の項目）に入ります：

- **チャートデータをエクスポート…**：チャート（マルチチャートレイアウトのとき）と時間の形式を選び、CSV をエクスポートします。ファイル名は `BTCUSDT-1h.csv` のようになります。

CSV には、チャートに読み込まれたすべての足が、チャートの表示どおりに入ります。現在の時間足、現在のチャートタイプ（たとえば平均足なら平均足の値）で、リプレイ中はリプレイの位置までです。各行は `time`、`open`、`high`、`low`、`close`、`volume` の順で、そのあとに表示中の各インジケーターが凡例に並べるすべてのラインが続きます（非表示のインジケーターやラインはエクスポートしません）。列名はラインの英語名（画面の言語によって変わりません）で、`MA9`、`Signal line` のようになり、名前が重なるときは `MA9 (VOL)` のようにインジケーターのコードが付きます。インジケーターの値は、チャート上の値とも、チャートライブラリの `computeIndicator()` が同じ足から計算した値ともまったく同じで、計算したとおりにすべての桁を書きます（浮動小数点演算のため末尾に誤差が出ることがあります。たとえば `82080.56000000011` は、チャートの小数桁に四捨五入すると凡例と同じになります）。インジケーターにまだ値がない足（MA20 の最初の 19 本など）は空欄です。価格帯別出来高のように足ごとに 1 つの値でないものはエクスポートせず、比較銘柄もエクスポートしません。

時間の形式は 2 つです：**ISO時間**はチャートで選んだタイムゾーンで、その時点のタイムゾーンオフセット付きで書きます。たとえば `2026-10-22T08:00:00+08:00` です（UTC は `Z` と書き、夏時間のあるタイムゾーンはそれぞれの日付のオフセットを使います）。**UNIXタイムスタンプ**は秒単位で、`1792627200` のようになります（ティックバーのようにミリ秒を持つ足は小数で書きます）。

`features: { screenshot: false }` でカメラボタンを外せます。`multiChart` をオフにしてエクスポートをオンにしているときは、レイアウトのボタンはエクスポート専用になります（表のアイコン）。`dataExport` を有効にしなくても、ページから `openDialog('exportData')` でエクスポートのウィンドウを開けます。たとえば自前のメニューに入れるときに使えます。
