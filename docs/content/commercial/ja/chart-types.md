# チャートタイプ

トップバーのチャートタイプメニューはグループごとに並んでいて、どのタイプにも中国語・英語・日本語・韓国語の名前があり、最後に独自の数種類の足が続きます。メソッドと状態では左の列の名前を使います：

| タイプ                                                | 説明                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ohlc`、`candles`、`hollow-candles`、`volume-candles` | バー、ローソク足、中空ローソク足、出来高ローソク足（幅が出来高に比例）                                                                                                                                                                                                                                                                                                                                                                                                              |
| `line`、`line-markers`、`step-line`                   | ライン、マーカー付きライン、ステップライン                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `area`、`hlc-area`、`baseline`                        | エリア、HLCエリア、ベースライン                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `columns`、`high-low`                                 | 棒グラフ（ペインの下端から伸び、1 本前の足より上がったか下がったかで色分け）、ハイロー                                                                                                                                                                                                                                                                                                                                                                                              |
| `footprint`、`tpo`                                    | 出来高フットプリント、タイム・プライス・オポチュニティ（商用版のオーダーフロー。下の「出来高フットプリントとタイム・プライス・オポチュニティ」を参照）：各足の価格ごとの成行買いと成行売りの出来高。取引日ごとに 30 分を 1 文字で表すマーケットプロファイル                                                                                                                                                                                                                         |
| `heikin-ashi`、`range`                                | 平均足、レンジ。現在の時間足の足から作ります。レンジの各足の値幅は直近 14 本の確定足の ATR（アベレージ・トゥルー・レンジ）から自動で決まり、丸め方は練行足と同じです                                                                                                                                                                                                                                                                                                                |
| `renko`                                               | 練行足：ブロックはブロックサイズの整数倍にそろい、直前のブロックをブロックサイズ 1 つ分超えると新しいブロックができ、転換には 2 つ分が必要です。設定：`method` は「サイズの決め方」で、`atr`（デフォルト。直近 `atrLength` 本の ATR、デフォルト 14）、`traditional`（固定の `box`）、`percentage`（現在値の `percentage`%、デフォルト 1）。`source` は `close`（デフォルト、終値）か `ohlc`（始値・高値・安値・終値）。`wicks` はヒゲ（デフォルトでオン。設定では色の「ヒゲ」の行） |
| `line-break`                                          | 新値足：終値が直近 `lines` 本（デフォルト 3）のラインの高値か安値を超えたときに新しいラインを描きます                                                                                                                                                                                                                                                                                                                                                                               |
| `kagi`                                                | カギ足：終値でラインを描き、同じ方向に進むあいだは伸び続け、極値から「転換ボックス数」だけ戻ると向きを変えます。上向きに直前の肩を超えたところから太く（陽線、上昇の色）、下向きに直前の腰を割ったところから細く（陰線、下落の色）なります。設定：`method` は「サイズの決め方」で、`atr`（デフォルト。直近 `atrLength` 本の ATR、デフォルト 14）、`traditional`（固定の `reversal`）、`percentage`（現在値の `percentage`%、デフォルト 1）                                          |
| `point-figure`                                        | ポイント＆フィギュア：X の列と O の列で、ボックスサイズも `method` で決まります（`atrLength`、固定の `box`、`percentage`）。`reversal` は列を替えるのに逆方向へ進む必要のあるボックス数（デフォルト 3）、`source` は `close`（デフォルト、終値）か `hl`（高値と安値）、`oneStepBack` は「1枠転換」（転換ボックス数が 1 のとき、1 枠だけの列は同じ列の中で転換します）                                                                                                               |
| `volume`、`turnover`                                  | 出来高バー、売買代金バー：`volume`（出来高）または `turnover`（売買代金）がたまるたびに 1 本確定します。デフォルトは `null` で、現在の時間足の平均的な 1 本分の量です。`input` は `bars`（デフォルト。現在の時間足の足を丸ごとまとめ、履歴があり、時間足が短いほど細かい）か `trades`（リアルタイムの約定、下を参照）                                                                                                                                                               |
| `tick`                                                | ティックバー：`count` 件（デフォルト 100）の約定ごとに 1 本。リアルタイムの約定から作ります                                                                                                                                                                                                                                                                                                                                                                                         |
| `imbalance`、`runs`                                   | インバランスバー、ランバー（商用版の情報駆動型の足）。リアルタイムの約定から作ります：`ticks` は最初に予想する 1 本あたりの約定件数（デフォルト 200）、`measure` は約定 1 件の重みで、`tick`（件数、デフォルト）、`volume`（出来高）、`turnover`（売買代金）                                                                                                                                                                                                                        |

設定は「チャート設定 → ローソク足」のいちばん上にあります。作成元、1 本あたりのサイズ（よく使ういくつかのサイズか、自分で入力）、約定の重みです。練行足、カギ足、ポイント＆フィギュアには上の設定があり、ATR や割合でサイズを決めるときは横に現在計算されたサイズが表示されます。「固定」に切り替えると、まず現在計算されたサイズを入力しておくので（多くの銘柄では使えない固定の 1 や 3 ではなく）、そこから自分で変えます。タイプごとの設定は状態に別々に保存され（`ChartView.barSettings`）、切り替えて戻ってきても元のままです。

練行足、カギ足、ポイント＆フィギュアは次のルールで作り、BTCUSDT、ETHUSDT などの日足・週足から計算したブロック、ライン、列はすべて照合済みです：

- 練行足は、最初の価格がグリッドのどのマスに入るかで、そのマスから始めます。ブロックの時間はそれを生んだ足の時間で、出来高は直前のブロックのまとまり以降の合計です。同じ価格で複数のブロックができたときは均等に分けます。始値・高値・安値・終値で作るとき、上昇した足は始値・安値・高値・終値、下落した足は始値・高値・安値・終値の順にたどり、各価格に出来高の 4 分の 1 を割り当てます。ヒゲは 2 つのブロックのまとまりのあいだの最高値か最安値まで伸び、価格がそのブロックの始値から逆方向にブロック 1 つ分以上超えたときだけ付きます。

- カギ足の最初のラインは最初の終値から始まり、終値が転換幅だけ離れたときに描かれます。ライン 1 本が 1 本の足で、始値は始点、終値は極値、時間はそれを始めた足の時間、出来高はその足から極値のある足までの合計です。
- ポイント＆フィギュアのボックスはボックスサイズの整数倍にそろい、列を替えるときは直前の列の最後のボックスから 1 つずらして始めます。列 1 つが 1 本の足で、始値は最初のボックスの価格、終値は最後のボックスの価格です。
- ATR や割合で決めるサイズは、最上位の桁の 10 のべき乗の半分の整数倍に丸めます（2137 → 2000、820 → 800）。ATR で決めるときは最後の確定足までで計算します（ATR インジケーターと同じアルゴリズム。形成中の足は数えません。ATR の期間を 1 にすると、サイズはちょうど前日の真の値幅になります）。固定のサイズにしたいときは「固定」で自分で入力します。
- 練行足、新値足、カギ足、ポイント＆フィギュアの最後の 1 本は、リアルタイムの価格ではなくブロック、ライン、ボックスの位置で止まります。価格軸の現在値のラインとラベルはこれまで通り最後の 1 本にあり、その横に色の薄い別のラベルがリアルタイムの価格を示します（最後の 1 本の終値より高ければ上昇の色、低ければ下落の色）。

時間足とチャートタイプはトップバーで同じ見た目です。星印を付けた項目がないときは、現在の時間足を表示するボタン（チャートタイプはアイコンだけを表示し、名前はマウスを乗せたときのツールチップに出ます）と、その後ろの淡い色の小さな矢印があり、それをクリックするとメニューが開きます。星印を付けた項目があるときは、星印の項目（チャートタイプはアイコンだけ）、最後に選んだ星印のない項目、独立した小さな矢印ボタンの順に並びます。最後に選んだ項目は星印の項目に切り替えても残るので、1 回のクリックでメニューを開かずに戻れます。メニューが開くのは小さな矢印をクリックしたときだけです。メニューの各行はマウスを乗せると行末に星印が出ます（星印を付けたものは常に表示）。星印を付けたタイプは状態の `favoriteChartTypes` に保存され、メソッドは `setFavoriteChartTypes(types)` です。

```ts
chart.setChartType('tick', { count: 500 });
chart.setChartType('volume', { volume: 1000, input: 'trades' });
chart.setChartType('imbalance', { ticks: 300, measure: 'volume' });
chart.setChartType('volume', { volume: null }); // 平均的な 1 本分の量に戻す
chart.setChartType('renko', { method: 'percentage', percentage: 1, source: 'ohlc', wicks: true });
chart.setChartType('kagi', { method: 'traditional', reversal: 2500 });
chart.setChartType('point-figure', { method: 'atr', atrLength: 20, reversal: 3, source: 'hl' });
```

**リアルタイムの約定から作る足**（`tick`、`imbalance`、`runs`、そして `input: 'trades'` の出来高バーと売買代金バー）は、`LiveListener.trades` でプッシュされた約定だけを使い、画面にもそう明記されます：

- **履歴がない**：`getBars()` が返すのは足だけなので、これらの足はそのチャートを開いて（または銘柄を替えて）から受け取った約定から始まります。最初の約定を受け取るまでチャートには「リアルタイムの約定を待っています」と表示され、その後は左下に何時から始まったかが表示されます。
- **切断すると欠ける**：データフィードが再接続後に補うのはふつう足であり、切断中の約定ではないので、時間足はそろっていても、約定から作る足はその期間が欠けます。
- **1 件はデータフィードがプッシュした 1 件**：データフィードがまとめた約定（同じ成行注文の複数の約定を 1 件にまとめたもの。Binance の USDⓈ-M 無期限先物など）をプッシュする場合、ティックバー 1 本に含まれる実際の約定はもっと多くなります。
- データフィードが足だけをプッシュし、約定をプッシュしないときは待ち続けます。
- これらは時間足とは関係ありません。トップバーではどの時間足も強調されず、時間足をクリックするとその時間足のローソク足に戻ります（`setTimeframe()` も同じ）。チャートは直近 100,000 件の約定を保持し、それより古い約定は捨てますが、そこから作った足は残ります。

## 出来高フットプリントとタイム・プライス・オポチュニティ

どちらもメニューの棒グラフ、ハイローの後、平均足の前にあり、名前は 成交量轨迹 / Volume footprint / 出来高フットプリント / 볼륨 풋프린트、时间价格机会 / Time Price Opportunity / タイム・プライス・オポチュニティ / 시간 가격 기회 です。設定は「チャート設定 → ローソク足」のいちばん上にあり、メソッドは `setChartType('footprint', { … })` と `setChartType('tpo', { … })` で、フィールドは次の通りです。

**出来高フットプリント**（`footprint`）：各足の横に価格ごとの行を並べ、左の列が成行売りの出来高、右の列が成行買いの出来高で、中央に細いローソク足があります。その下にそれぞれの列の合計、さらにその下の小さな枠にデルタ（買い − 売り）と合計の出来高を書きます。

| フィールド                                   | デフォルト           | 説明                                                                                                                                                                                                                      |
| -------------------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rowSize`、`atrLength`、`ticksPerRow`        | `auto`、14、10       | 行のサイズ：`auto` は直近 `atrLength` 本の足の ATR の 5 分の 1 をティックに丸めたもの（銘柄や時間足を替えると計算し直し、設定には現在計算された行のサイズが表示されます）。`manual` は 1 行あたり `ticksPerRow` ティック  |
| `display`                                    | `cluster`            | 表示モード：`cluster` クラスター（各マスが同じ幅）、`profile` プロファイル（マスが出来高の大きさに応じてローソク足から外へ伸びる）                                                                                        |
| `type`                                       | `buy-sell`           | タイプ：`buy-sell` 買いと売り、`delta` 買い − 売りの 1 列、`total` 合計の 1 列、`ladder` ラダー（各行で大きいほうだけに色を付ける）                                                                                       |
| `gradient`、`sell1`…`sell4`、`buy1`…`buy4`   | オン、テーマに従う   | 背景を出来高で 4 段階の濃さに分けます（その足の自分の側の最小から最大までを 4 等分）。オフにすると 2 段階目を使います。色が `null` のときは、テーマの上昇・下落の色から作った 4 段階です                                  |
| `valueArea`、`valueAreaPercent`              | オン、70             | バリューエリア：上端と下端に破線を引きます                                                                                                                                                                                |
| `poc`、`pocColor`                            | オン、テーマの文字色 | POC：出来高が最大の行を行全体で塗りつぶします                                                                                                                                                                             |
| `summary`                                    | オン                 | サマリー情報の表示：2 列の合計と、デルタ・合計の出来高の小さな枠                                                                                                                                                          |
| `imbalance`                                  | 300                  | インバランス（%）：ある行の成行買いの出来高が 1 つ下の行の成行売りの出来高の 300% 以上（斜めに比較）なら買いのインバランス、ある行の成行売りの出来高が 1 つ上の行の成行買いの出来高の 300% 以上なら売りのインバランスです |
| `highlight`、`buyHighlight`、`sellHighlight` | オン、テーマに従う   | 強調表示：インバランスのマスの外側に縦線を引きます。買いは右、売りは左                                                                                                                                                    |
| `stacked`、`stackedLevels`                   | オフ、3              | 積み重なりレベル：同じ方向のインバランスが 3 行以上続くと、その足から右へゾーンを描き、価格がそのゾーンに戻るまで伸ばします                                                                                               |

出来高フットプリントには約定 1 件ずつとそのアグレッサーが必要で、足からは割り出せません：

- **データの出どころ**：履歴はデータフィードの `getTradeMinutes()` が返す 1 分ごと・価格ごとの出来高、開いたあとはプッシュされた約定を使います（`side` が必須で、ない約定は数えません）。取得するのは画面上の足だけで、新しいものから順にさかのぼり、1 回で最大 6 時間分、同時に 2 リクエストまでです。同じ銘柄の複数のチャートは 1 つのデータを共有します。
- **誤った数値は出さない**：足はその約定がすべてそろったときだけ描き、そうでなければ足の下に「読み込み中」「約定なし」「失敗」（しばらくして自動で再試行）と書き、チャートの左下に理由を一言書きます。確定した足はデータフィードの足の出来高とも照合し、合わないとき（たとえば切断中にプッシュされた約定を取りこぼしたとき）はもう一度取得します。履歴があり、取得し直したものと足の差が 1000 分の 1 以内ならそれを使い（プラットフォームによっては、まとめた約定の最後の数件をときどき次の 1 分に入れることがあります）、差が大きいか履歴がないときは「約定なし」とします。
- **どこまでさかのぼれるか**：データフィードの `getTradeMinutes()` がどこまで返せるかによります。それがないか、直近のひとまとまりしか返さないときは、出来高フットプリントはおおむねチャートを開いた 1 分から始まります（その 1 分自体は、それが終わって取得できるようになってから埋まり、取得できなければずっと「約定なし」です）。
- **リプレイ**：リプレイの位置までの約定だけを使います。秒足には対応しません（約定は分単位で保存するため）。1 本の足が 2000 行を超えると描かず、行ごとのティックを大きくするよう促します。

**タイム・プライス・オポチュニティ**（`tpo`、マーケットプロファイル）：価格は終値のラインで表し、取引日ごとに 1 つのプロファイルをその日の始まりの位置に描きます。30 分ごとに 1 文字（A から Z、a から z、そしてまた A から）で、その 30 分に価格が到達した行すべてに置きます。右側はその日の各行の出来高です。

| フィールド                               | デフォルト             | 説明                                                                                                                                                                                                                                        |
| ---------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `period`、`periodUnit`                   | 1、`D`                 | 期間：何日（`D`）、何週（`W`）、何か月（`M`）で 1 つのプロファイルにするか。銘柄の取引カレンダーに従います                                                                                                                                  |
| `block`                                  | `30m`                  | ブロックサイズ：`5m` `10m` `15m` `30m` `1h` `2h` `4h`                                                                                                                                                                                       |
| `rowSize`、`ticksPerRow`                 | `auto`、10             | 行のサイズ：`auto` は直近 300 本の足の価格範囲を 80 行に分け、5、50、500…の倍数に丸めます。`manual` は 1 行あたり `ticksPerRow` ティック                                                                                                    |
| `valueArea`                              | 70                     | バリューエリア（%、文字の数で計算）                                                                                                                                                                                                         |
| `color1`…`color4`                        | ピンク、緑、シアン、紫 | 色のグラデーション：A、N、a、n がこの 4 色で、そのあいだは 13 文字ごとに次の色へ移り変わります                                                                                                                                              |
| `blocks`、`letters`、`opacity`、`expand` | オン、オン、44、オフ   | ブロック、文字（マスが小さすぎるときは書きません）、バリューエリア外側の不透明度（%）、ブロックを延長（各文字をその時間の位置に置く）                                                                                                       |
| `poc`、`vah`、`val`                      | オン                   | POC（文字が最も多い行で、行全体を塗りつぶす）と、バリューエリアの上端・下端の破線。左側にラベルが付きます                                                                                                                                   |
| `nakedPoc`、`nakedPocColor`              | オフ、POC の色         | ネイキッド POC：それ以前の最大 20 期間のプロファイルの POC のうち、その後どの足も触れていないものを、プロファイルの右からチャートの右端まで破線で描きます。その後に足が触れると、ラインは描かれなくなります                                 |
| `poorHigh`、`poorLow`、`singlePrints`    | オフ                   | プアハイ・プアロー（最高値・最安値の行に 2 文字以上ある）にラインを引き、シングルプリント（途中で 1 文字しかない行）をその日を横切る帯として描きます                                                                                        |
| `midpoint`、`open`、`close`              | オフ                   | TPO ミッドポイント、始値、終値のラベル                                                                                                                                                                                                      |
| `initialBalance`、`initialBalanceBlocks` | オン、2                | イニシャルバランスレンジ（IBR）：最初の 2 ブロック（最初の 1 時間）の範囲を、プロファイルの左に縦線で描きます。文字はブロックの期間内での時間順に並び、約定のないブロックも 1 文字分を占めます                                              |
| `volumeProfile`、`volumeValues`          | オン、オフ             | 各行の出来高（各ブロックの出来高を、そのブロックがかかる長さに応じて各行に分けます。ブロック単位で計算するので、チャートの時間足には影響されません）。バリューエリア内は色が濃くなります。`volumeValues` は各行の値とその日の合計を書きます |
| `volumeVah`、`volumeVal`、`volumePoc`    | オフ、オフ、オン       | 出来高のバリューエリアの上端・下端と POC のライン（POC はデフォルトで赤）。色は `volumeLineColor`、`volumePocColor`                                                                                                                         |
| `volumePlacement`                        | `left`                 | 配置：各行を出来高の領域の左（`left`）から伸ばすか、右（`right`）から伸ばすか                                                                                                                                                               |

文字はチャート自身の足から作ります。タイム・プライス・オポチュニティを選ぶと、チャートは現在の時間足とブロックサイズの両方を合成できる足を取得するようになるので（たとえば日足チャートに 30 分ブロックなら 30 分足を取得）、履歴、リアルタイム、リプレイのどれも足と一致します。データフィードにブロックを合成できる足がないときは、チャートにそう表示します。POC の候補が複数の行で同数のときはプロファイルの中央に最も近い行を選び（それも同じなら上の行）、バリューエリアは POC から始めて、毎回上の行と下の行を比べて文字の多いほうを加え（同数なら POC に近いほう、それも同じなら上の行）、次の行を加えると 70% を超えるところで止めます。

まだ実装していないもの：ある文字でプロファイルを分割すること、1 つ前のプロファイルとの結合、各ラインの「価格が戻るまで延長」、取引セッション（プレマーケット、通常取引、アフターマーケット、カスタム）ごとに分けたプロファイル、サマリー情報の表、これらの水準でのアラート。出来高フットプリントのサマリー情報の表と、インバランスやデルタのアラートもまだありません。
