# 단축키

차트에 포커스가 있을 때(예를 들어 차트를 누른 뒤) 아래 키를 쓸 수 있으며, 주요 시세 소프트웨어의 관례와 같습니다. Mac에서 Alt는 ⌥, Ctrl은 ⌘, Shift는 ⇧이며, 화면에도 그렇게 적습니다. 입력란에서 글자를 칠 때는 동작하지 않고, 창, 대화 상자, 메뉴 안에서는 Alt나 Ctrl이 들어간 키만 동작합니다. `?`나 Ctrl+/로 단축키 목록을 엽니다. 상단 바 버튼과 그리기 도구 모음의 툴팁, 우클릭 메뉴에도 해당하는 키가 적혀 있습니다.

| 키                                                          | 동작                                                                                                                                                                                             | 필요한 토글                                          |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| 영문자를 바로 입력                                          | 종목 검색을 열고, 입력한 글자를 채워 둠                                                                                                                                                          | `symbolSearch`                                       |
| 숫자 입력(단위 `s`, `m`, `h`, `D`, `W`, `M`을 이어 써도 됨) | 바꿀 주기를 현재 차트에 표시합니다. `15`는 15분, `4h`, `1D` 등. Enter로 바꾸고 Esc로 취소합니다. 주기 목록에는 없지만 데이터 피드가 합성할 수 있는 주기는 사용자의 사용자 지정 주기에 추가됩니다 |                                                      |
| `/`                                                         | 지표 창                                                                                                                                                                                          | `indicators`                                         |
| `?`, Ctrl+/                                                 | 단축키 목록                                                                                                                                                                                      |                                                      |
| ← →(Shift를 누르면 반 화면씩)                               | 좌우 스크롤                                                                                                                                                                                      |                                                      |
| ↑, + / ↓, −                                                 | 확대 / 축소                                                                                                                                                                                      |                                                      |
| End                                                         | 최신 봉으로 이동                                                                                                                                                                                 |                                                      |
| Alt+R                                                       | 차트 보기 초기화                                                                                                                                                                                 |                                                      |
| Alt+I, Alt+L, Alt+P                                         | 스케일 반전, 로그 스케일, 퍼센트 스케일(다시 누르면 일반으로)                                                                                                                                    |                                                      |
| Alt+A                                                       | 알림 창을 열고 십자선의 가격을 채워 둠. 포인터가 메인 창에 없으면 현재가                                                                                                                         | `alerts`                                             |
| Alt+S                                                       | 스크린샷(이미지 다운로드)                                                                                                                                                                        | `screenshot`                                         |
| Alt+Shift+S                                                 | 이미지를 클립보드에 복사                                                                                                                                                                         | `screenshot`                                         |
| Esc                                                         | 그리는 중인 그리기, 리플레이 시작점 선택을 취소                                                                                                                                                  |                                                      |
| Alt+T, Alt+H, Alt+J, Alt+V, Alt+C, Alt+F, Alt+Shift+R       | 추세선, 수평선, 수평 레이, 수직선, 교차선, 피보나치 되돌림, 사각형(Alt+R은 이미 보기 초기화). 다시 누르면 취소                                                                                   | `drawings`, 그리고 도구가 `drawingTools`에 있어야 함 |
| Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z                               | 그리기 실행 취소 / 다시 실행                                                                                                                                                                     | `drawings`, `history`                                |
| Delete, Backspace                                           | 선택한 그리기 삭제                                                                                                                                                                               | `drawings`                                           |
| Ctrl+C, Ctrl+V                                              | 선택한 그리기 복사, 붙여넣기                                                                                                                                                                     | `drawings`                                           |

토글로 끈 기능의 단축키는 동작하지 않고 목록에도 나오지 않습니다. `features: { shortcuts: false }`는 방향키, Delete 같은 차트 자체의 키까지 포함해 모든 단축키를 끄며, 차트 설정 "조작"의 "키보드 단축키" 토글도 함께 숨깁니다. 사용자도 이 토글로 차트마다 단축키를 끌 수 있습니다.
