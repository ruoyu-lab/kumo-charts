# 차트 유형

상단 바의 차트 유형 메뉴는 그룹별로 나열되며, 유형마다 중국어, 영어, 일본어, 한국어 이름이 있고, 뒤에 자체 봉 몇 가지가 이어집니다. 메서드와 상태에서는 왼쪽 열의 이름을 씁니다:

| 유형                                                  | 설명                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ohlc`, `candles`, `hollow-candles`, `volume-candles` | 바, 캔들, 할로우캔들, 볼륨 캔들(너비가 거래량에 비례)                                                                                                                                                                                                                                                                                                                                                                          |
| `line`, `line-markers`, `step-line`                   | 라인, 마커가 있는 라인, 스텝 라인                                                                                                                                                                                                                                                                                                                                                                                              |
| `area`, `hlc-area`, `baseline`                        | 영역, HLC 영역, 베이스라인                                                                                                                                                                                                                                                                                                                                                                                                     |
| `columns`, `high-low`                                 | 컬럼(창 아래쪽에서 올라오며, 이전 봉보다 올랐는지 내렸는지로 색을 칠함), 하이-로우                                                                                                                                                                                                                                                                                                                                             |
| `footprint`, `tpo`                                    | 볼륨 풋프린트, 시간 가격 기회(상업용의 오더 플로우. 아래 "볼륨 풋프린트와 시간 가격 기회" 참고): 봉마다 가격별 시장가 매수·매도 거래량. 거래일마다 30분을 글자 하나로 나타내는 마켓 프로파일                                                                                                                                                                                                                                   |
| `heikin-ashi`, `range`                                | 하이킨 아시, 레인지. 현재 주기의 봉으로 만듭니다. 레인지 봉 하나의 고저 폭은 최근 마감된 봉 14개의 평균 실제 범위(ATR)로 자동으로 정하며, 반올림 방식은 렌코와 같습니다                                                                                                                                                                                                                                                        |
| `renko`                                               | 렌코: 벽돌은 벽돌 크기의 정수배에 맞춰지고, 직전 벽돌을 벽돌 크기 하나만큼 넘으면 새 벽돌이 생기며, 반전에는 두 개가 필요합니다. 설정: `method`는 "크기 기준"으로, `atr`(기본값, 최근 `atrLength`개 봉의 ATR, 기본 14), `traditional`(고정 `box`), `percentage`(현재가의 `percentage`%, 기본 1). `source`는 `close`(기본값, 종가) 또는 `ohlc`(시가·고가·저가·종가). `wicks`는 꼬리(기본으로 켜짐. 설정에서는 색상의 "꼬리" 행) |
| `line-break`                                          | 라인브레이크: 종가가 최근 `lines`개(기본 3) 라인의 최고나 최저를 넘으면 새 라인을 그립니다                                                                                                                                                                                                                                                                                                                                     |
| `kagi`                                                | 카기: 종가로 선을 그리며, 같은 방향으로 가는 동안 계속 늘어나고, 극값에서 "반전 박스 수"만큼 되돌리면 방향을 바꿉니다. 위로 직전 어깨를 넘은 곳부터 굵어지고(양선, 상승 색), 아래로 직전 허리를 깬 곳부터 가늘어집니다(음선, 하락 색). 설정: `method`는 "크기 기준"으로, `atr`(기본값, 최근 `atrLength`개 봉의 ATR, 기본 14), `traditional`(고정 `reversal`), `percentage`(현재가의 `percentage`%, 기본 1)                     |
| `point-figure`                                        | 포인트앤피겨: X 열과 O 열이며, 박스 크기도 `method`로 정합니다(`atrLength`, 고정 `box`, `percentage`). `reversal`은 열을 바꾸려면 반대로 가야 하는 박스 수(기본 3), `source`는 `close`(기본값, 종가) 또는 `hl`(고가와 저가), `oneStepBack`은 "1박스 반전"(반전이 1박스일 때 1박스짜리 열은 같은 열 안에서 방향을 바꿉니다)                                                                                                     |
| `volume`, `turnover`                                  | 거래량 바, 거래대금 바: `volume`(거래량) 또는 `turnover`(거래대금)가 쌓일 때마다 하나씩 마감합니다. 기본값 `null`은 현재 주기의 평균 봉 하나만큼의 양입니다. `input`은 `bars`(기본값. 현재 주기의 봉을 통째로 합치며, 과거 데이터가 있고, 주기가 짧을수록 촘촘함) 또는 `trades`(실시간 체결, 아래 참고)                                                                                                                        |
| `tick`                                                | 틱 바: 체결 `count`건(기본 100)마다 하나. 실시간 체결로 만듭니다                                                                                                                                                                                                                                                                                                                                                               |
| `imbalance`, `runs`                                   | 불균형 바, 런 바(상업용의 정보 기반 바). 실시간 체결로 만듭니다: `ticks`는 처음에 예상하는 봉당 체결 건수(기본 200), `measure`는 체결 한 건의 가중치로, `tick`(건수, 기본값), `volume`(거래량), `turnover`(거래대금)                                                                                                                                                                                                           |

설정은 "차트 설정 → 캔들"의 맨 위에 있습니다. 구성 기준, 봉 하나의 크기(자주 쓰는 몇 가지 크기, 또는 직접 입력), 체결 가중치입니다. 렌코, 카기, 포인트앤피겨는 위의 설정이며, ATR이나 비율로 크기를 정하면 옆에 현재 계산된 크기가 표시됩니다. "고정"으로 바꾸면 먼저 현재 계산된 크기를 채워 두므로(대부분의 종목에서 쓸 수 없는 고정 1이나 3이 아니라), 거기서 직접 고칩니다. 유형마다의 설정은 상태에 따로 저장되며(`ChartView.barSettings`), 다시 돌아와도 그대로입니다.

렌코, 카기, 포인트앤피겨는 아래 규칙으로 만들며, BTCUSDT, ETHUSDT 등의 일봉, 주봉으로 계산한 벽돌, 선, 열은 모두 대조해 확인했습니다:

- 렌코는 첫 가격이 격자의 어느 칸에 들어가는지에 따라 그 칸부터 시작합니다. 벽돌의 시간은 그것을 만든 봉의 시간이고, 거래량은 직전 벽돌 묶음 이후의 합계이며, 같은 가격으로 여러 벽돌이 생기면 똑같이 나눕니다. 시가·고가·저가·종가로 만들 때 상승한 봉은 시가, 저가, 고가, 종가 순으로, 하락한 봉은 시가, 고가, 저가, 종가 순으로 지나가며, 각 가격이 거래량의 4분의 1을 차지합니다. 꼬리는 두 벽돌 묶음 사이의 최고가나 최저가까지 뻗고, 가격이 이 벽돌의 시가에서 반대 방향으로 벽돌 하나 이상 넘었을 때만 생깁니다.

- 카기의 첫 선은 첫 종가에서 시작하고, 종가가 거기서 반전 폭만큼 벌어지면 그려집니다. 선 하나가 봉 하나이며, 시가는 시작점, 종가는 극값, 시간은 그것을 시작한 봉의 시간, 거래량은 그 봉부터 극값이 있는 봉까지의 합계입니다.
- 포인트앤피겨의 박스는 박스 크기의 정수배에 맞춰지고, 열을 바꿀 때는 직전 열의 마지막 박스에서 한 칸 비켜 시작합니다. 열 하나가 봉 하나이며, 시가는 첫 박스의 가격, 종가는 마지막 박스의 가격입니다.
- ATR이나 비율로 정한 크기는 가장 높은 자릿수의 10의 거듭제곱의 절반의 정수배로 반올림합니다(2137 → 2000, 820 → 800). ATR로 정할 때는 마지막으로 마감된 봉까지로 계산합니다(ATR 지표와 같은 알고리즘. 형성 중인 봉은 세지 않습니다. ATR 기간을 1로 하면 크기는 정확히 전날의 실제 범위입니다). 고정된 크기를 원하면 "고정"으로 직접 입력하세요.
- 렌코, 라인브레이크, 카기, 포인트앤피겨의 마지막 봉은 실시간 가격이 아니라 벽돌, 선, 박스에서 멈춥니다. 가격축의 현재가 선과 라벨은 그대로 마지막 봉에 있고, 그 옆에 색이 더 옅은 라벨이 따로 실시간 가격을 표시합니다(마지막 봉의 종가보다 높으면 상승 색, 낮으면 하락 색).

주기와 차트 유형은 상단 바에서 같은 모양입니다. 별표를 단 항목이 없으면 현재 주기를 쓴 버튼(차트 유형은 아이콘만 표시하고, 이름은 마우스를 올렸을 때 툴팁에 나옴)과 그 뒤의 흐린 작은 화살표가 있고, 그것을 누르면 메뉴가 열립니다. 별표를 단 항목이 있으면 별표 항목(차트 유형은 아이콘만), 가장 최근에 고른 별표 없는 항목, 따로 떨어진 작은 화살표 버튼 순입니다. 최근에 고른 항목은 별표 항목으로 바꿔도 남아 있어서 메뉴를 열지 않고 한 번에 되돌아갈 수 있으며, 작은 화살표를 눌러야만 메뉴가 열립니다. 메뉴의 각 행은 마우스를 올리면 행 끝에 별표가 나타납니다(별표를 단 것은 늘 표시). 별표를 단 유형은 상태의 `favoriteChartTypes`에 저장되고, 메서드는 `setFavoriteChartTypes(types)`입니다.

```ts
chart.setChartType('tick', { count: 500 });
chart.setChartType('volume', { volume: 1000, input: 'trades' });
chart.setChartType('imbalance', { ticks: 300, measure: 'volume' });
chart.setChartType('volume', { volume: null }); // 평균 봉 하나만큼의 양으로 돌아갑니다
chart.setChartType('renko', { method: 'percentage', percentage: 1, source: 'ohlc', wicks: true });
chart.setChartType('kagi', { method: 'traditional', reversal: 2500 });
chart.setChartType('point-figure', { method: 'atr', atrLength: 20, reversal: 3, source: 'hl' });
```

**실시간 체결로 만드는 봉**(`tick`, `imbalance`, `runs`, 그리고 `input: 'trades'`인 거래량 바와 거래대금 바)은 `LiveListener.trades`로 푸시된 체결만 쓰며, 화면에도 그렇게 밝혀 둡니다:

- **과거 데이터가 없음**: `getBars()`는 봉만 주므로 이 봉들은 차트를 연(또는 종목을 바꾼) 뒤에 받은 체결부터 시작합니다. 첫 체결을 받기 전에는 차트에 "실시간 체결을 기다리는 중"이라고 표시되고, 그 뒤로는 왼쪽 아래에 몇 시부터인지 표시됩니다.
- **연결이 끊기면 빈 곳이 생김**: 데이터 피드가 다시 연결한 뒤 보충하는 것은 보통 봉이지 끊긴 동안의 체결이 아니므로, 시간 봉은 온전하지만 체결로 만드는 봉은 그 시간만큼 비게 됩니다.
- **한 건은 데이터 피드가 푸시한 한 건**: 데이터 피드가 묶은 체결(같은 시장가 주문의 여러 체결을 한 건으로 합친 것. 바이낸스 USDⓈ-M 무기한 등)을 푸시하면, 틱 바 하나에 들어가는 실제 체결은 더 많아집니다.
- 데이터 피드가 봉만 푸시하고 체결을 푸시하지 않으면 계속 기다립니다.
- 이 봉들은 주기와 상관없습니다. 상단 바에서 어떤 주기도 강조되지 않고, 주기를 누르면 그 주기의 캔들로 돌아갑니다(`setTimeframe()`도 같음). 차트는 최근 100,000건의 체결을 보관하며, 더 이전의 체결을 버린 뒤에도 그것으로 만든 봉은 남습니다.

## 볼륨 풋프린트와 시간 가격 기회

둘 다 메뉴에서 컬럼, 하이-로우 다음, 하이킨 아시 앞에 있으며, 이름은 成交量轨迹 / Volume footprint / 出来高フットプリント / 볼륨 풋프린트, 时间价格机会 / Time Price Opportunity / タイム・プライス・オポチュニティ / 시간 가격 기회입니다. 설정은 "차트 설정 → 캔들"의 맨 위에 있고, 메서드는 `setChartType('footprint', { … })`, `setChartType('tpo', { … })`이며, 필드는 아래와 같습니다.

**볼륨 풋프린트**(`footprint`): 봉마다 옆에 가격별로 행을 나누어, 왼쪽 열은 시장가 매도 거래량, 오른쪽 열은 시장가 매수 거래량이고, 가운데에 가는 캔들이 있습니다. 그 아래는 두 열 각각의 합계이고, 다시 그 아래 작은 상자에 델타(매수 − 매도)와 총 거래량을 씁니다.

| 필드                                         | 기본값               | 설명                                                                                                                                                                                                                     |
| -------------------------------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `rowSize`, `atrLength`, `ticksPerRow`        | `auto`, 14, 10       | 행 크기: `auto`는 최근 `atrLength`개 봉의 평균 실제 범위의 5분의 1을 틱으로 반올림한 것(종목이나 주기를 바꾸면 다시 계산하며, 설정에 현재 계산된 행 크기가 표시됨). `manual`은 행마다 `ticksPerRow`틱                    |
| `display`                                    | `cluster`            | 표시: `cluster` 클러스터(칸마다 너비가 같음), `profile` 프로필(칸이 거래량 크기에 따라 캔들에서 바깥으로 자람)                                                                                                           |
| `type`                                       | `buy-sell`           | 유형: `buy-sell` 매수 및 매도, `delta` 매수 − 매도 한 열, `total` 총계 한 열, `ladder` 사다리(행마다 큰 쪽에만 색을 칠함)                                                                                                |
| `gradient`, `sell1`…`sell4`, `buy1`…`buy4`   | 켜짐, 테마 따름      | 배경을 거래량에 따라 네 단계 농도로 나눕니다(이 봉의 자기 쪽 최소에서 최대 사이를 4등분). 끄면 두 번째 단계를 씁니다. 색이 `null`이면 테마의 상승·하락 색으로 만든 네 단계입니다                                         |
| `valueArea`, `valueAreaPercent`              | 켜짐, 70             | 가치 영역: 위아래 끝에 점선을 그립니다                                                                                                                                                                                   |
| `poc`, `pocColor`                            | 켜짐, 테마의 글자 색 | POC: 거래량이 가장 큰 행을 행 전체로 칠합니다                                                                                                                                                                            |
| `summary`                                    | 켜짐                 | 요약 정보 표시: 두 열의 합계와 델타·총 거래량의 작은 상자                                                                                                                                                                |
| `imbalance`                                  | 300                  | 불균형(%): 어떤 행의 시장가 매수 거래량이 한 칸 아래 행의 시장가 매도 거래량의 300% 이상이면(대각선 비교) 매수 불균형, 어떤 행의 시장가 매도 거래량이 한 칸 위 행의 시장가 매수 거래량의 300% 이상이면 매도 불균형입니다 |
| `highlight`, `buyHighlight`, `sellHighlight` | 켜짐, 테마 따름      | 강조 표시: 불균형 칸의 바깥쪽에 세로선을 그립니다. 매수는 오른쪽, 매도는 왼쪽                                                                                                                                            |
| `stacked`, `stackedLevels`                   | 꺼짐, 3              | 스택 레벨: 같은 방향의 불균형이 3행 이상 이어지면 이 봉에서 오른쪽으로 영역을 그리고, 가격이 이 영역으로 돌아올 때까지 늘립니다                                                                                          |

볼륨 풋프린트에는 체결 하나하나와 그 공격자 측이 필요하며, 봉으로는 알아낼 수 없습니다:

- **데이터 출처**: 과거는 데이터 피드의 `getTradeMinutes()`가 주는 1분마다 가격별 거래량을, 연 뒤에는 푸시된 체결을 씁니다(`side`가 반드시 있어야 하며, 없는 체결은 세지 않습니다). 화면에 있는 봉만 가져오고, 최신 것부터 거슬러 올라가며, 한 번에 최대 6시간, 동시에 요청 두 개입니다. 같은 종목의 여러 차트는 데이터 하나를 함께 씁니다.
- **틀린 숫자는 표시하지 않음**: 봉은 그 체결이 모두 도착했을 때만 그리고, 그렇지 않으면 봉 아래에 "불러오는 중", "체결 없음" 또는 "실패"(잠시 후 자동으로 다시 시도)를 쓰며, 차트 왼쪽 아래에 이유를 한 줄 씁니다. 마감된 봉은 데이터 피드 봉의 거래량과도 대조합니다. 맞지 않으면(예를 들어 연결이 끊겼을 때 푸시된 체결을 놓쳤으면) 한 번 더 가져옵니다. 과거 데이터가 있고 다시 가져온 것과 봉의 차이가 1000분의 1 이내면 그것을 쓰고(일부 플랫폼은 가끔 묶은 체결의 마지막 몇 건을 다음 1분에 넣습니다), 차이가 크거나 과거 데이터가 없으면 "체결 없음"으로 표시합니다.
- **얼마나 멀리 볼 수 있나**: 데이터 피드의 `getTradeMinutes()`가 얼마나 멀리까지 줄 수 있는지에 달려 있습니다. 그것이 없거나 최근 한 묶음만 주면 볼륨 풋프린트는 대체로 차트를 연 그 1분부터 시작합니다(그 1분 자체는 끝나서 가져올 수 있게 되어야 채워지며, 가져올 수 없으면 계속 "체결 없음"입니다).
- **리플레이**: 리플레이 위치까지의 체결만 씁니다. 초 단위 주기는 지원하지 않습니다(체결은 분 단위로 저장). 봉 하나가 2000행을 넘으면 그리지 않고, 행당 틱을 늘리라고 알려 줍니다.

**시간 가격 기회**(`tpo`, 마켓 프로파일): 가격은 종가의 선이고, 거래일마다 프로파일 하나를 그날이 시작되는 곳에 그립니다. 30분마다 글자 하나(A부터 Z, a부터 z, 그리고 다시 A부터)이며, 그 30분 동안 가격이 닿은 행마다 하나씩 놓습니다. 오른쪽은 그날 각 행의 거래량입니다.

글자는 차트 자체의 봉으로 만듭니다. 시간 가격 기회를 고르면 차트가 가져오는 봉이 현재 주기와 블록 크기를 모두 합성할 수 있는 것으로 바뀌므로(예를 들어 일봉 차트에 30분 블록이면 30분봉을 가져옴), 과거, 실시간, 리플레이 모두 봉과 일치합니다. 데이터 피드에 블록을 합성할 수 있는 봉이 없으면 차트에 그렇게 표시합니다. POC 후보가 여러 행으로 같으면 프로파일 가운데에 가장 가까운 행을 고르고(그것도 같으면 위쪽 행), 가치 영역은 POC에서 시작해 매번 위 행과 아래 행을 비교해 글자가 많은 행을 더하며(같으면 POC에 가까운 행, 그것도 같으면 위쪽 행), 다음 행을 더하면 70%를 넘을 때 멈춥니다.

아직 만들지 않은 것: 어떤 글자에서 프로파일을 나누기, 이전 프로파일과 합치기, 각 선의 "가격이 돌아올 때까지 연장", 거래 세션(장전, 정규장, 장후, 사용자 지정)별로 나눈 프로파일, 요약 정보 표, 그리고 이 수준들에서의 알림. 볼륨 풋프린트의 요약 정보 표와 불균형, 델타의 알림도 아직 없습니다.
