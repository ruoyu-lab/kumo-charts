# Kumo Charts 상업용

Kumo Charts 상업용은 오픈 소스 [Kumo Charts](../../ko/index.md) 위에 만든 상업용 컴포넌트로, [상업 라이선스](license.md)를 구매해 사용합니다. 핵심은 **프로 차트**입니다. 모든 도구를 갖춘 시세 차트로, 자체 시세 데이터만 연결하면 웹 페이지에 바로 넣을 수 있고, Vue, React, 일반 웹 페이지 어디서나 쓸 수 있습니다.

```ts
import { createProChart } from '@kumo-charts/pro-chart';

const chart = createProChart(document.getElementById('chart')!, {
  datafeed: myDatafeed,
  symbol: '600519.SH'
});
```

[빠른 시작](getting-started.md)부터 읽어 보세요.

## 무엇이 들어 있나

- **프로 차트**(`@kumo-charts/pro-chart`): 상단 바의 종목 검색, 종목 비교, 주기, 차트 유형, 지표와 지표 템플릿, 리플레이, 실행 취소와 다시 실행, 스크린샷과 차트 데이터 내보내기, 왼쪽의 그리기 도구, 멀티 차트 레이아웃, 우클릭 메뉴, 차트 설정과 지표 설정 창, 그리고 가격, 지표, 그리기의 [알림](alerts.md). 상단 바는 통째로 없애고 페이지 자체의 것으로 바꿀 수 있고, 페이지의 관심 종목 목록은 종목 검색의 별표에 연결할 수 있으며, 버튼, 우클릭 메뉴, 지표, 그리기 도구에는 페이지 자체의 것을 추가할 수 있습니다.
- **오더 플로우**: 볼륨 풋프린트와 시간 가격 기회(TPO) 두 가지 [차트 유형](chart-types.md), 거래량 델타, 누적 거래량 델타, 매수·매도 거래량 세 가지 [지표](indicators.md), 대량 체결과 호가창 히트맵, 그리고 시장가 매수·매도로 나눈 매물대.
- **정보 기반 바**: 불균형 바와 런 바로, 실시간 체결로 만듭니다.
- **수식 지표**: 중국 시세 소프트웨어 방식으로 쓴 [수식](formula.md)이 그대로 체결마다 실시간으로 계산하는 지표가 됩니다.

이 모든 것이 프로 차트에 들어 있고, 상업 라이선스 키 하나로 모두 쓸 수 있습니다.

## 사기 전에 써 보기

내 컴퓨터의 개발 서버에 있는 페이지(`localhost`, `127.0.0.1` 등)는 라이선스 키가 필요 없고 워터마크도 없으므로 모든 기능을 써 볼 수 있습니다. 정식 웹사이트나 앱에 올리면 라이선스 키가 없는 차트는 왼쪽 아래에 "Kumo Charts 상업용 · 라이선스 미등록, 평가 전용"을 표시합니다. 라이선스는 개인과 기업 두 종류이며 [kumocharts.com](https://kumocharts.com/ko/#pricing)에서 구매하고, 결제하면 바로 라이선스 키를 받습니다. 규칙은 [라이선스](license.md)를 참고하세요.

## 화면 둘러보기

차트에서 우클릭: 차트 보기 초기화(Alt+R, Mac에서는 ⌥R), 가격 복사, 이 가격에 알림 추가(클릭 한 번으로 추가), 알림 추가…(Alt+A, 알림 창 열기), 이 봉부터 리플레이, 지표 추가, 그리기 숨기기·삭제, 알림 삭제, 스크린샷, 차트 설정. 그리기나 알림선에서 우클릭하면 각자의 동작이 나옵니다(그리기: 그 선에 알림 추가…, 복사, 잠금, 숨기기, 삭제. 알림선: 알림 편집…, 일시정지, 삭제. 알림선을 더블클릭해도 편집이 열립니다). 가격축에서 우클릭: 이 가격에 알림 추가…, 가격축 초기화, 자동 스케일, 스케일 반전(Alt+I), 일반, 퍼센트(Alt+P), 100 기준, 로그(Alt+L), 그리고 현재가의 라벨, 선, 봉 마감 카운트다운이며, 차트마다 따로 저장됩니다. 보조 창의 가격축에는 초기화와 자동 스케일만 있습니다. 시간축에서 우클릭하면 시간축을 초기화할 수 있습니다.

멀티 차트 레이아웃은 상단 바 오른쪽에 있습니다: 한 장, 좌우 두 장, 상하 두 장, 세 장의 두 가지 배치(왼쪽 큰 것 하나와 오른쪽 작은 것 둘, 왼쪽 작은 것 둘과 오른쪽 큰 것 하나), 네 장, 그리고 여섯 장의 네 가지 배치(2행 3열, 3행 2열, 왼쪽 큰 것 하나와 오른쪽 작은 것 다섯, 위쪽 큰 것 하나와 아래쪽 작은 것 다섯). 다른 차트가 현재 차트를 따라 종목 변경, 주기 변경, 십자선 이동, 시간 맞추기를 하게 할 수 있습니다(주기는 기본적으로 따라가지 않아 차트마다 다른 주기를 볼 수 있습니다). 차트 사이의 경계는 모두 드래그해서 크기를 조절할 수 있고, 각 차트는 최소 200×120 픽셀을 유지하며 공간이 부족하면 똑같이 나눕니다. 경계를 더블클릭하면 그 방향의 경계가 기본 위치로 돌아갑니다.

시간축 오른쪽 아래(가격축 밑)에는 차트 시간의 시간대가 `UTC+8`처럼 표시됩니다. 클릭하면 거래소 시간(종목 거래 캘린더의 시간대. 데이터 피드가 캘린더를 주지 않는 종목은 각 플랫폼의 암호화폐처럼 UTC 기준 24시간 거래로 봅니다), UTC, 로컬 시간, 또는 주요 도시의 시간대를 고를 수 있고, 항목마다 현재의 UTC 오프셋이 붙습니다. 고른 것은 상태에 저장되어 모든 차트가 함께 씁니다. 바뀌는 것은 표시되는 시간뿐이며, 봉은 여전히 종목의 거래 캘린더로 나눕니다. 리플레이 작은 창의 시간도 이 시간대를 따릅니다.

그리기를 선택하면 그 옆에 자주 쓰는 도구의 툴바(색, 선 두께, 선 종류, 복사, 잠금, 삭제)가 떠오릅니다. 툴바의 톱니바퀴를 누르거나 그리기를 더블클릭하면 그리기 설정 창이 열리며, 탭은 네 개입니다: 스타일(선, 채우기, 왼쪽·오른쪽 연장, 화살표, 피보나치 각 레벨의 값·색·표시), 텍스트(내용, 색, 크기, 굵게·기울임, 정렬과 위치), 좌표(각 점의 시간과 가격, 정확히 입력 가능), 표시할 주기(초, 분, 시간, 일, 주, 월 중 어떤 주기에서 표시할지). 변경은 입력하고 드래그하는 대로 바로 적용되고, 실행 취소할 때는 한 번의 편집이 한 단계입니다. 입력란 하나에 이어서 친 글자나 불투명도 슬라이더를 한 번 드래그한 것은 실행 취소 한 번으로 통째로 돌아갑니다. 도구마다 사용자가 마지막으로 준 스타일을 기억해 새로 그리는 그리기에 바로 씁니다. 텍스트 그리기는 더블클릭하면 여전히 차트 위에서 바로 편집합니다.

리플레이는 차트 위에 떠 있는 작은 창으로 조작합니다. 왼쪽 끝의 점을 잡고 원하는 위치로 끌 수 있고, 위치는 저장되며, 더블클릭하면 원래 자리로 돌아갑니다. 리플레이 시작점을 고르는 동안에는 포인터가 있는 봉의 오른쪽, 리플레이가 숨길 부분이 흐리게 표시됩니다.

멀티 차트 레이아웃에서는 같은 종목의 차트가 함께 리플레이합니다. 리플레이를 누르면 그 종목을 표시하는 모든 차트에서 시작점을 고를 수 있고, 마우스가 있는 차트에 숨길 부분이 표시됩니다. 클릭한 차트에서 시작하며, 그 차트가 현재 차트가 되어 리플레이 조작은 그 차트의 주기로 진행되고, 같은 종목의 다른 차트는 같은 시간으로 따라옵니다. 그보다 큰 주기의 차트는 대신 그 차트만큼 잘게 나눈 봉으로 합성하므로, 진행 중인 봉이 점점 자라나고 그 이후의 가격은 보이지 않습니다. 데이터를 바꾸는 데 잠시 걸리며, 그동안 그 차트는 비어 있습니다. 다른 종목의 차트는 평소대로 실시간 시세를 표시합니다. 같은 종목의 어느 차트에서 리플레이를 끝내도 모두 함께 실시간으로 돌아갑니다.

## 스크린샷과 데이터 내보내기

상단 바 오른쪽의 카메라 버튼은 메뉴입니다:

- **이미지 다운로드**(Alt+S): 현재 차트를 PNG로 저장하며, 파일 이름은 `BTCUSDT-1h.png` 같은 식입니다.
- **이미지 복사**(Alt+Shift+S, Mac에서는 ⌥⇧S. Ctrl+Shift+S는 일부 브라우저에서 브라우저 자체의 스크린샷입니다): 현재 차트의 이미지를 클립보드에 넣어 채팅이나 문서에 바로 붙여 넣을 수 있습니다. 브라우저가 페이지에서 클립보드에 이미지를 넣지 못하게 할 때(오래된 브라우저, 또는 https가 아닌 페이지)는 대신 그 이미지를 다운로드하고 짧게 알려 줍니다.

데이터 내보내기는 기본적으로 표시되지 않습니다. `features: { dataExport: true }`로 켜면 레이아웃 메뉴(상단 바 오른쪽 멀티 차트 레이아웃 버튼의 마지막 항목)에 들어갑니다:

- **차트 데이터 내보내기…**: 차트(멀티 차트 레이아웃일 때)와 시간 형식을 골라 CSV로 내보내며, 파일 이름은 `BTCUSDT-1h.csv` 같은 식입니다.

CSV에는 차트에 불러온 모든 봉이 차트에 보이는 그대로 들어갑니다. 현재 주기, 현재 차트 유형(예를 들어 하이킨아시라면 하이킨아시 값)이며, 리플레이 중에는 리플레이 위치까지입니다. 각 행은 차례로 `time`, `open`, `high`, `low`, `close`, `volume`이고, 그다음은 표시 중인 각 지표가 범례에 나열하는 모든 선입니다(숨긴 지표와 선은 내보내지 않습니다). 열 이름은 선의 영어 이름(화면 언어에 따라 바뀌지 않음)으로 `MA9`, `Signal line` 같은 식이고, 이름이 겹치면 `MA9 (VOL)`처럼 뒤에 지표 코드가 붙습니다. 지표 값은 차트에 보이는 값, 그리고 차트 라이브러리의 `computeIndicator()`가 같은 봉으로 계산한 값과 완전히 같으며, 계산된 그대로 모든 자릿수를 씁니다(부동소수점 연산 때문에 `82080.56000000011`처럼 끝에 오차가 있을 수 있으며, 차트의 소수 자릿수로 반올림하면 범례와 같아집니다). 지표에 아직 값이 없는 봉(MA20의 처음 19개 등)은 비워 둡니다. 매물대처럼 봉마다 값이 하나가 아닌 것은 내보내지 않으며, 비교 종목도 내보내지 않습니다.

시간 형식은 두 가지입니다: **ISO 시간**은 차트에서 고른 시간대로, 그 시점의 시간대 오프셋을 붙여 `2026-10-22T08:00:00+08:00`처럼 씁니다(UTC는 `Z`로 쓰고, 서머타임이 있는 시간대는 날짜마다 그날의 오프셋을 씁니다). **UNIX 타임스탬프**는 초 단위로 `1792627200`처럼 씁니다(틱 봉처럼 밀리초가 있는 봉은 소수로 씁니다).

`features: { screenshot: false }`로 카메라 버튼을 없앨 수 있습니다. `multiChart`를 끄고 내보내기를 켜 두면 레이아웃 버튼은 내보내기 전용이 됩니다(표 아이콘). `dataExport`를 켜지 않아도 페이지에서 `openDialog('exportData')`로 내보내기 창을 열 수 있으므로, 예를 들어 자체 메뉴에 넣을 수 있습니다.
