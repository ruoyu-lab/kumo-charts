# 수식

중국 시세 소프트웨어 방식으로 쓴 지표 수식이 그대로 프로 차트의 지표가 됩니다. 봉마다 실시간으로 계산하고, 지표 창에 나열되며, 사용자는 기본 제공 지표처럼 추가하고 파라미터와 선을 바꿀 수 있고, 알림도 걸 수 있습니다. 수식을 `customIndicators`에 쓰고(또는 나중에 `registerIndicator()`로 등록하고), 알고리즘의 `definition` 대신 `formula`를 씁니다:

```ts
import { createProChart, type CustomIndicator } from '@kumo-charts/pro-chart';

const MYMACD: CustomIndicator = {
  name: { en: 'My MACD', zh: '我的 MACD' }, // 지표 창에서 코드 뒤에 나오는 이름
  group: 'oscillators',
  formula: {
    type: 'MYMACD', // 코드. 지표 창과 범례에 표시되며, 기본 제공 지표와 같은 이름일 수 없음
    name: 'MYMACD', // 범례의 이름
    formula: `
      DIF:EMA(CLOSE,SHORT)-EMA(CLOSE,LONG);
      DEA:EMA(DIF,MID);
      MACD:(DIF-DEA)*2,COLORSTICK;
    `,
    params: { SHORT: 12, LONG: 26, MID: 9 }
  }
};

const chart = createProChart(container, {
  datafeed,
  symbol: '600519.SH',
  customIndicators: [MYMACD]
});
chart.addIndicator('MYMACD', { params: { SHORT: 6 } });
```

수식 지표의 라이선스는 상업 라이선스에 포함됩니다. `name`, `group`, `origin`은 다른 [사용자 지표](custom-indicators.md)와 같습니다.

## 옵션

| 옵션        | 설명                                                                                                                                                        |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `type`      | 코드. 예: `MYMACD`. 지표 창, 범례, 상태에서 모두 이것을 쓰며, 기본 제공 지표나 다른 사용자 지표와 같은 이름일 수 없습니다                                   |
| `name`      | 범례에 표시하는 이름                                                                                                                                        |
| `formula`   | 수식 텍스트                                                                                                                                                 |
| `params`    | 파라미터. 예: `{ N: 9 }`. 범위를 붙일 수도 있습니다: `{ N: { default: 9, min: 1, max: 100, integer: true } }`. 지표 설정 창은 이것에 따라 입력을 제한합니다 |
| `overlay`   | `true`면 메인 창에 그리고, 아니면 따로 보조 창 하나에 그립니다                                                                                              |
| `precision` | 소수 자릿수. `price`는 가격을 따르고(메인 창에 그릴 때의 기본값), `volume`은 거래량용                                                                       |
| `levels`    | 수평 기준선. 예: `[20, 80]`                                                                                                                                 |
| `range`     | 보조 창의 고정 스케일 범위. 예: `{ min: 0, max: 100 }`                                                                                                      |
| `timeZone`  | 시간 함수가 쓰는 시간대. 예: `Asia/Shanghai`. 기본값은 차트가 시간을 표시하는 시간대이며, 사용자가 시간대를 바꾸면 새 시간대로 다시 계산합니다              |
| `library`   | 참조할 수 있는 다른 수식. 아래 "다른 수식 참조" 참고                                                                                                        |

## 잘못 썼을 때

수식은 `createProChart()`나 `registerIndicator()` 때 컴파일되며, 잘못 쓰면 바로 `FormulaError`(`@kumo-charts/pro-chart`에서 가져옴)를 던집니다. `code`는 어떤 오류인지, `span`은 오류가 난 곳, `describe('zh')`는 중국어 설명입니다(`describe()`는 영어 설명):

```ts
import { FormulaError } from '@kumo-charts/pro-chart';

try {
  await chart.registerIndicator({ formula: { type: 'X', name: 'X', formula: 'A:MA(C,N);' } });
} catch (error) {
  if (error instanceof FormulaError) {
    error.span; // { line: 1, column: 8, length: 1 }
    error.describe('zh'); // "N"既不是前面定义过的变量、参数，也不是 CLOSE 这样的行情数据。
  }
}
```

## 문법

- `이름:식;`은 선 하나를 그립니다. `이름:=식;`은 중간 변수만 정의합니다. 이름이 없는 식도 선을 그립니다.
- 연산자: `+ - * /`, 비교 `> < >= <= = <>`, 논리 `AND OR NOT`(`&& || !`로도 씀). 우선순위는 높은 것부터 `* /`, `+ -`, 비교, `NOT`, `AND`, `OR`입니다. 그래서 괄호 없는 `NOT C>O`는 중국 수식에서 흔히 쓰는 `NOT(C>O)`와 같이 "양봉이 아님"입니다. `NOT`을 비교의 한쪽에 둘 때는 괄호가 필요하며, `C>NOT(O)`처럼 씁니다.
- 이름은 대소문자를 구분하지 않고 중국어도 쓸 수 있습니다. 중국어 전각 문장 부호(`；：，（）`)는 자동으로 인식하며, 따옴표 안의 글자는 그대로 둡니다(`'买入，加仓'`의 전각 쉼표는 바뀌지 않음). 글자와 참조는 중국어 따옴표 `‘’`, `“”`로 감쌀 수도 있으며, 영문 따옴표로 감싸면 안에 중국어 따옴표를 넣을 수 있습니다.
- 주석: `{ … }`와 `// …`.
- 시세 데이터: `OPEN/O`, `HIGH/H`, `LOW/L`, `CLOSE/C`, `VOL/V/VOLUME`.
- 선 속성: `COLORRED` 등의 색, `COLOR`에 여섯 자리 BBGGRR을 붙인 것, `NODRAW`, `STICK`, `COLORSTICK`, `VOLSTICK`, `DOTLINE`, `DASHLINE`, `LINETHICK1`–`9`(선 두께, "그리기 함수" 참고).

## 함수

| 분류     | 함수                                                                                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 이동평균 | `MA` `EMA` `EXPMA` `SMA` `MEMA` `DMA` `WMA`                                                                                                                           |
| 참조     | `REF` `BARSLAST` `BARSSINCE` `BARSCOUNT` `BARSLASTCOUNT`                                                                                                              |
| 통계     | `SUM` `HHV` `LLV` `HHVBARS` `LLVBARS` `COUNT` `EVERY` `EXIST` `SUMBARS` `STD` `STDP` `VAR` `VARP` `AVEDEV` `DEVSQ` `SLOPE` `FORCAST`                                  |
| 신호     | `CROSS` `LONGCROSS` `FILTER` `VALUEWHEN` `LAST` `NDAY` `UPNDAY` `DOWNNDAY`                                                                                            |
| 지표     | `SAR`                                                                                                                                                                 |
| 시간     | `DATE` `TIME` `YEAR` `MONTH` `DAY` `HOUR` `MINUTE` `WEEKDAY` `BARPOS`                                                                                                 |
| 논리     | `IF` `IFF` `IFN` `NOT` `BETWEEN` `RANGE` `ISUP` `ISDOWN` `ISEQUAL`                                                                                                    |
| 수학     | `ABS` `MAX` `MIN` `SQRT` `POW` `LN` `LOG` `EXP` `INTPART` `FRACPART` `CEILING` `FLOOR` `ROUND` `ROUND2` `SIGN` `MOD` `REVERSE` `SIN` `COS` `TAN` `ASIN` `ACOS` `ATAN` |
| 기타     | `DRAWNULL`                                                                                                                                                            |

몇몇 함수의 세부 사항:

- `LAST(X,A,B)`: A개 전부터 B개 전까지(양 끝 포함) 모든 봉에서 X가 성립하면 1. A가 0이면 첫 봉부터, B가 0이면 현재 봉까지입니다. 구간의 시작이 첫 봉보다 앞이거나 A가 B보다 작으면 0.
- `NDAY(X,Y,N)`: 최근 N개 봉 모두에서 X>Y. `UPNDAY(X,M)`, `DOWNNDAY(X,M)`: 최근 M개 봉 모두가 직전 봉보다 큼(작음). 같으면 세지 않습니다.
- `RANGE(A,B,C)`: A가 B보다 크고 C보다 작으면 1이며, 양 끝은 포함하지 않습니다. 양 끝도 포함하려면 `BETWEEN`을 씁니다.
- `ROUND(X)`는 정수로, `ROUND2(X,N)`은 소수 N자리로 반올림합니다. 둘 다 반올림이며, 음수의 0.5도 0에서 멀어지는 쪽으로 반올림합니다(`ROUND(-2.5)`는 -3). 쓰인 그대로의 십진수로 반올림하므로 `ROUND2(1.005,2)`는 1.01입니다. N의 소수 부분은 버리며, 음수면 무효값입니다.
- `FRACPART(X)`는 소수 부분이며 부호가 있습니다: `FRACPART(-3.5)`는 -0.5.
- `VALUEWHEN(COND,X)`: COND가 마지막으로 성립한 봉의 X. 처음 성립하기 전에는 무효값.
- `SUMBARS(X,A)`: 현재 봉부터 거슬러 X를 A 이상이 될 때까지 더하려면 몇 개가 필요한지. 현재 봉만으로 충분하면 1이고, 모두 더해도 모자라면 그때까지의 봉 수입니다. X의 무효값은 0으로 봅니다.
- `SAR(N,S,M)`: 파라볼릭 SAR. S는 스텝, M은 한계값이며 둘 다 퍼센트로 `SAR(10,2,20)`처럼 씁니다. 처음 N개 봉에는 값이 없으며 시작점을 정하는 데 씁니다. 그다음 봉의 종가가 첫 봉의 종가보다 높으면 상승으로 시작하고 SAR은 이 N개 봉의 최저가에서 출발하며, 아니면 하락으로 시작하고 최고가에서 출발합니다. 그 뒤로 봉마다 추세의 극값에 가까워지며, 가속도는 S%에서 시작해 새 극값을 낼 때마다 S%씩 늘어 최대 M%입니다. 직전 두 봉의 범위 안으로는 들어가지 않고, 가격이 교차하면 방향을 바꾸어 이전 추세의 극값에서 다시 시작합니다.

### 기간

기간 인수(`MA(C,N)`의 `N` 등)는 숫자, 파라미터, 또는 그 사칙연산일 수 있고, 계열일 수도 있습니다. `HHV(H,BARSLAST(CROSS(C,MA(C,5)))+1)`은 마지막으로 5일 이동평균을 상향 교차한 이후의 최고가, `SUM(V,BARSLAST(CROSS(C,MA(C,5)))+1)`은 그 기간의 거래량입니다. `LONGCROSS`, `FILTER`, `SAR`을 빼면 기간은 모두 계열일 수 있습니다.

- 숫자나 파라미터로 쓸 때 기간은 정수여야 하고 그 함수의 하한(다음 항목 참고) 이상이어야 하며, 그렇지 않으면 컴파일할 때 `invalid-period`를 알리며 하한이 얼마인지 밝힙니다. `REF`의 기간을 음수로 쓰면 그 뒤의 봉(미래 데이터)을 참조하게 되어 `future-reference`를 알립니다.
- 계열을 기간으로 쓰면 봉마다 그 봉의 기간 값을 쓰고, 소수 부분은 버립니다(2.7은 2). 기간이 무효값이거나 음수면 결과는 무효값입니다.
- 0의 의미는 숫자로 쓸 때와 같습니다. `SUM`, `HHV`, `LLV`, `HHVBARS`, `LLVBARS`, `COUNT`와 `LAST`의 A에 0을 쓰면 첫 봉부터 세고, `REF`의 0은 현재 봉입니다. 다른 함수의 기간은 최소 1(`STD`, `VAR`, `SLOPE`, `FORCAST`는 최소 2)이며, 더 작으면 무효값입니다.
- 봉 수가 기간보다 적을 때도 숫자로 쓸 때와 같습니다. `COUNT`, `EXIST`는 있는 만큼 세고, `EVERY`, `NDAY`, `UPNDAY`, `DOWNNDAY`와 `LAST`는 0, 나머지는 무효값입니다.
- `EMA`, `SMA` 같은 재귀형 이동평균은 봉마다 그 봉의 기간으로 계산하며, 기간이 무효한 봉은 결과가 무효값이고 재귀에도 참여하지 않습니다.

## 그리기 함수

봉 위에 신호를 그립니다. 쓰는 방식은 중국 시세 소프트웨어의 수식과 같으며, 따로 한 문장으로 쓰고 뒤에 색을 붙일 수 있습니다:

```text
金叉:=CROSS(MA(C,5),MA(C,10));
DRAWICON(金叉,LOW,1);
DRAWTEXT(金叉,HIGH+MA(HIGH-LOW,20),'金叉'),COLORRED;
STICKLINE(VOL>MA(VOL,20)*2,OPEN,CLOSE,0.8,0),COLORYELLOW;
DRAWBAND(MA(C,5),COLORRED,MA(C,20),COLORGREEN);
DRAWLINE(H>=HHV(H,20),H,L<=LLV(L,20),L,1),COLORMAGENTA,LINETHICK2;
```

| 함수                                     | 그리는 방식                                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `STICKLINE(조건,가격1,가격2,너비,속빈)`  | 조건이 성립하는 봉에 가격 1부터 가격 2까지 기둥을 그립니다. 너비 0은 가는 선, 0.8은 캔들 몸통과 같은 너비, 1.1 이상은 간격을 꽉 채웁니다. 속빈이 0이 아니면 테두리만 그립니다                                                                                                                                                                                                                           |
| `DRAWTEXT(조건,가격,'글자')`             | 가격 위치에 글자를 씁니다(가격을 중심으로)                                                                                                                                                                                                                                                                                                                                                              |
| `DRAWNUMBER(조건,가격,숫자)`             | 가격 위치에 숫자를 씁니다(가격을 중심으로). 숫자는 계열이어도 됩니다. 정수는 소수 없이, 나머지 수는 수식의 소수 자릿수로 범례와 같이 씁니다                                                                                                                                                                                                                                                             |
| `DRAWICON(조건,가격,아이콘)`             | 아이콘 1은 위쪽 화살표로 끝이 아래에서 가격을 가리키고, 2는 아래쪽 화살표로 위에서 가격을 가리킵니다. 다른 번호는 점을 그립니다                                                                                                                                                                                                                                                                         |
| `POLYLINE(조건,가격)`                    | 조건이 성립하는 점을 차례로 꺾은선으로 잇고, 사이의 봉은 건너뜁니다. `PLOYLINE`으로도 쓸 수 있습니다                                                                                                                                                                                                                                                                                                    |
| `VERTLINE(조건)`                         | 조건이 성립하는 봉에 창의 위쪽 끝부터 아래쪽 끝까지 세로선을 긋습니다                                                                                                                                                                                                                                                                                                                                   |
| `DRAWLINE(조건1,가격1,조건2,가격2,연장)` | 조건 1이 성립하면 시작점을 기록하고(다시 성립하면 새 시작점으로 바뀜), 그 뒤 조건 2가 성립하면 시작점부터 거기까지 직선을 긋습니다. 시작점은 거기서 다 쓰고, 다음 선은 조건 1이 다시 성립하기를 기다립니다. 두 조건이 같은 봉에서 성립하면 먼저 거기서 이전 선을 끝내고, 그다음 거기서 새 선을 시작합니다. 연장: 0은 연장 안 함, 1은 창 오른쪽 끝까지 연장, 2나 10은 왼쪽으로, 3이나 11은 양쪽으로 연장 |
| `DRAWBAND(값1,색1,값2,색2)`              | 값 1이 값 2보다 높은 곳은 색 1로, 반대는 색 2로 두 값 사이를 채웁니다. 색은 `COLORRED` 같은 색 이름이나 `COLOR`에 여섯 자리 BBGGRR을 붙여 씁니다. 채우기는 반투명이라 봉을 가리지 않습니다                                                                                                                                                                                                              |
| `DRAWKLINE(고가,시가,저가,종가)`         | 이 네 값으로 캔들을 그립니다. 종가가 시가보다 낮지 않으면 상승이며, 상승·하락 색은 차트 테마를 따릅니다                                                                                                                                                                                                                                                                                                 |
| `PARTLINE(가격,조건1,색1,조건2,색2,…)`   | 가격의 선을 그리며, 봉마다 처음 성립하는 조건의 색을 쓰고, 아무것도 성립하지 않는 곳은 그리지 않습니다. 색이 바뀌는 곳에서 두 구간이 이어지므로 색이 바뀌는 선 하나가 됩니다. 조건과 색은 한 쌍이나 여러 쌍을 줄 수 있습니다                                                                                                                                                                            |
| `FILLRGN(가격1,가격2,조건1,색1,…)`       | 두 가격 사이를 채우며, 봉마다 처음 성립하는 조건의 색을 쓰고, 아무것도 성립하지 않는 곳은 채우지 않습니다. 채우기는 반투명이며 `DRAWBAND`와 같은 농도입니다                                                                                                                                                                                                                                             |
| `DRAWGBK(조건,색)`                       | 조건이 성립하는 봉 뒤로 창 전체의 배경을 그 색으로 옅게 물들이며, 이어진 봉들은 한 덩어리로 이어집니다. 봉 아래에 있어 봉을 가리지 않습니다                                                                                                                                                                                                                                                             |

- 그리기 함수의 인수는 조건이 성립하지 않을 때도 봉마다 계산하므로, `MA`, `REF` 같은 함수를 인수에 넣어도 결과가 바뀌지 않습니다.
- 너비, 속빈, 아이콘 번호, 연장은 숫자나 파라미터여야 하고, 글자는 따옴표로 감싸야 합니다.
- 색을 쓰지 않으면 화살표는 차트 테마의 매수·매도 색을, `DRAWKLINE`은 테마의 상승·하락 색을, 다른 도형은 테마의 선 색을 차례로 씁니다. 중국 시세 소프트웨어에서는 1번, 2번 아이콘이 빨강, 초록으로 고정이지만, 여기서는 테마를 따라 초록이 상승인 차트에서 매수를 빨강으로 그리지 않게 합니다.
- `LINETHICK1`–`9`는 선 두께를 정합니다. 일반 선과 `POLYLINE`, `DRAWLINE`, `VERTLINE` 모두 같으며, 1이 기본 두께, 2–9는 2–9픽셀입니다. `DOTLINE`, `DASHLINE`은 그것을 점선, 파선으로 그립니다. 사용자가 지표 설정에서 바꾼 선 두께가 우선합니다.
- `DRAWLINE`은 미리 선을 긋지 않습니다. 선은 조건 2가 성립하는 봉이 나타날 때 그어지며, 그은 뒤에는 바뀌지 않습니다.
- 그리기는 범례에 표시되지 않습니다. 스케일은 기둥의 양 끝, 표시, 숫자, 꺾은선의 각 점, 직선의 양 끝과 띠 영역을 위한 공간을 남기며, 세로선은 공간을 차지하지 않습니다. 그리기만 있는 보조 창도 제대로 표시됩니다.
- 그리기 함수는 따로 한 문장이어야 하며, 식에 넣거나 이름에 대입할 수 없습니다.

## 다른 수식 참조

`"수식이름.선이름"`으로 다른 수식의 선 하나를 읽으며, 그 수식의 기본 파라미터를 씁니다:

```text
XG:CROSS("MACD.DIF","MACD.DEA") AND "KDJ.J"<20;
```

뒤에 괄호를 붙이면 자체 파라미터를 줄 수 있습니다. 그 수식 파라미터의 순서대로 각각 숫자나 이 수식의 파라미터이며, 주지 않은 것은 기본값을 씁니다:

```text
快:"MACD.DIF"(5,20); 慢:"MACD.DIF"; 金叉:CROSS("MACD.DIF"(N,20,9),"MACD.DEA"(N,20,9));
```

- 기성 수식은 모두 이름으로 참조할 수 있습니다: `MA`, `BOLL`, `MACD`, `KDJ`, `RSI`, `CCI`, `WR`, `BIAS`, `TRIX`, `OBV`.
- 자신의 수식도 `library` 옵션에 넣으면 참조할 수 있으며, 같은 이름이면 기성 수식보다 우선합니다: `{ library: { 我的均线: { formula: 'FAST:MA(C,N);', params: { N: 5 } } } }`.
- 이름은 대소문자를 구분하지 않으며, 중국어 따옴표 `“”`도 됩니다.
- 같은 수식을 같은 파라미터로 여러 번 참조해도 한 번만 계산합니다. 서로 참조해 순환하거나, 없는 수식이나 선을 참조하면 오류를 내고 위치를 가리킵니다. 수식은 자기 코드(`type`)로 자신을 알아봅니다. 같은 이름의 수식을 참조하면 자기 자신을 참조하는 것이 되며, 범례에 표시하는 `name`은 치지 않으므로 `name: 'MACD'`인 수식도 기성 `"MACD.DIF"`를 그대로 참조할 수 있습니다.
- 참조된 수식 자체가 잘못되었으면 `broken-reference`를 알리며, 위치는 참조한 곳을 가리키고, 설명에 그 수식이 몇 행 몇 열에서 무엇이 틀렸는지가 들어갑니다. `error.referenced`는 그 수식 원래의 `FormulaError`입니다.

## 중국 시세 소프트웨어와의 차이

- **무효값**: 데이터가 모자랄 때(예: `MA(C,5)`의 처음 4개 봉), 0으로 나눌 때, 무효값과 비교할 때는 모두 결과가 무효값이며 차트에 그리지 않습니다. 이동평균 계열 함수는 무효값을 건너뜁니다.
- **봉이 기간보다 적을 때의 `HHV`, `LLV`, `SUM`**: 봉 수가 아직 기간에 미치지 못하면 여기서는 무효값이며(`HHV(H,20)`의 처음 19개 봉은 그리지 않음), 차트 라이브러리의 기본 제공 지표와 같습니다. 중국 시세 소프트웨어는 보통 있는 봉만으로 값을 계산하므로 처음 구간은 서로 다르고, 그 뒤로는 완전히 같습니다. 첫 봉부터 값이 있게 하려면 `IF(BARSCOUNT(C)>=20,HHV(H,20),HHV(H,0))`처럼 씁니다(기간 0은 첫 봉부터 셈).
- **아직 지원하지 않음**: 나머지 그리기 함수(`DRAWBMP`, `DRAWSL`, `DRAWTEXT_FIX` 등), 매매 함수(`BUY`, `SELL`), `AMOUNT`(봉에 거래대금이 없어 결과는 무효값), 주기를 넘나드는 참조(예: `"MACD.DIF#WEEK"`).
- **시간**: `DATE`는 중국 시세 소프트웨어와 같이 1900년부터 세고(2026-10-21은 `1261021`), `TIME`은 `HHMMSS`(9:30은 `93000`), `WEEKDAY`의 0은 일요일입니다. 시간은 봉의 **시작 시간**을 쓰지만, 중국 시세 소프트웨어의 분봉은 끝 시간을 씁니다. 같은 9:30–9:35 봉에서 여기서는 `TIME`이 `93000`, 그쪽은 `93500`입니다.
- **미래 함수**: `ZIG`, `PEAK`, `PEAKBARS`, `TROUGH`, `TROUGHBARS`, `BACKSET`, `REFX`, `REFXV`, `CONST`, `XMA`, `CURRBARSCOUNT`, `TOTALBARSCOUNT`, `ISLASTBAR`, `BARSTATUS`, `BARSNEXT`, `FILTERX`는 그 뒤의 봉을 씁니다. 그린 선과 신호가 새 봉이 오면서 다시 쓰이므로(리페인트) 돌이켜 볼 때는 보기 좋아도 실시간으로는 얻을 수 없어 지원하지 않습니다. 쓰면 `future-function` 오류를 내고 위치를 가리키며, 다른 방식이 있으면 함께 알려 줍니다. 예를 들어 `ZIG`가 찾는 고점·저점은 `HHV`, `LLV`에 `BARSLAST`를 더해 이미 확정된 것을 구할 수 있고, `XMA`는 `MA`로 바꿀 수 있습니다.
- **SAR의 시작점**: 소프트웨어마다 `SAR`을 시작하는 방식이 조금씩 다르며, 여기서의 시작점은 위에서 설명한 대로입니다. 그래서 처음 구간의 값과 전환점은 다른 소프트웨어와 다를 수 있고, 몇 번 전환한 뒤에는 같아집니다. 시작 구간이 지나면(보통 처음 수십 개 봉 안에서 몇 번 전환한 뒤) 차트 라이브러리의 기본 제공 SAR과 봉마다 일치합니다(파라미터를 소수로: `SAR(10,2,20)`은 0.02, 0.02, 0.2에 대응). `N`이 1이면 처음부터 끝까지 일치합니다.
