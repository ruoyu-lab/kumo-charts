# 종목 비교

상단 바 종목 이름 뒤의 ⊕로 비교 창을 엽니다. 종목을 검색하고 행을 누르면(또는 Enter) "동일한 % 척도"로 추가합니다. 포인터를 행에 올리면 오른쪽에 버튼 세 개가 나타나 고를 수 있습니다:

| 위치                  | 메서드의 `placement` | 그리는 방식                                                                                                                                                                                       |
| --------------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 동일한 % 척도(기본값) | `percent`            | 메인 창의 가격 스케일에 그리며, 스케일을 퍼센트로 바꿉니다. 모든 종목이 시야 안 첫 봉의 종가부터 세어 모두 0%에서 시작하고, 각자의 등락으로 움직이며, 드래그나 확대·축소할 때마다 다시 계산합니다 |
| 새로운 가격 척도      | `scale`              | 메인 창에 자체 가격 스케일로 그립니다. 첫 번째는 왼쪽 가격축에 두고, 그다음부터는 축이 없습니다(값은 범례에서 봄)                                                                                 |
| 새 창                 | `pane`               | 따로 창 하나에 자체 가격 스케일로 그립니다                                                                                                                                                        |

창 위쪽에는 현재 차트가 비교 중인 종목이 나열되며, 각각 뺄 수 있습니다. 추가해도 창이 닫히지 않으므로 이어서 추가할 수 있습니다. 메인 창이 일반이나 로그 스케일일 때 "동일한 % 척도"로 종목을 추가하면 퍼센트로 바뀝니다(100 기준일 때는 그대로이며, 마찬가지로 종목마다 자기 첫 봉부터 셉니다). 나중에 가격축 우클릭 메뉴에서 일반으로 되돌릴 수 있습니다.

- 비교 종목은 차트의 현재 주기로 데이터를 가져오고(메인 창처럼 데이터 피드의 봉 주기로 합성), 왼쪽으로 끌어 더 이전 봉을 불러올 때 함께 불러오며, 실시간 데이터가 있으면 함께 움직입니다(봉을 푸시하든 체결을 푸시하든 상관없음). 리플레이 중에도 마찬가지로 리플레이한 부분만 표시합니다.
- 범례의 한 줄에 이름과 종가(그 종목 자체의 소수 자릿수)를 표시하고, 가격축에 최신 값(퍼센트 스케일에서는 퍼센트)을 표시하며, 현재가 라벨과 겹치면 자동으로 비켜 놓습니다. 포인터를 그 줄에 올리면 보이기/숨기기, 설정, 삭제 버튼이 나옵니다. 설정 창에서는 위치, 스타일(차트 유형과 같은 이름, 같은 방식: 바, 캔들, 할로우캔들, 라인, 마커가 있는 라인, 스텝 라인, 영역, HLC 영역, 베이스라인, 컬럼, 하이-로우. 메서드의 `style`은 `ohlc`, `candles`, `hollow-candles`, `line`, `line-markers`, `step-line`, `area`, `hlc-area`, `baseline`, `columns`, `high-low`), 색과 선 두께(라인과 영역 다섯 가지. 나머지는 상승·하락 색)를 바꿀 수 있고, 바꾸면 바로 적용됩니다. 색을 지정하지 않으면 팔레트 끝에서부터 차례로, 지표가 자주 쓰는 색을 피해 가져옵니다.
- 메인 창의 종목을 바꿔도 비교 종목은 남습니다. 차트마다 자기 비교 종목이 있으며, `ChartView.comparisons`(`{ id, symbol, placement, style, color, width, visible }`)에 저장됩니다.

```ts
const id = await chart.addComparison('ETHUSDT'); // 동일한 % 척도
await chart.addComparison('XAUUSDT', { placement: 'pane', style: 'area' });
await chart.updateComparison(id, { color: '#0d9488', width: 3 });
chart.on('comparisonsChange', ({ chart: index, comparisons }) => save(index, comparisons));
```
